## Prompted

出现这个错误，是因为你现在处于 Python 交互模式（左侧显示 >>>），而你输入的 e:、cd 和 python test_baidu.py 都是 系统命令。
就像你在“翻译官”的对话框里输入了“帮我关下门”，翻译官听不懂，他只能翻译句子。
解决方法：退出 Python 模式，回到 PowerShell
请严格按照以下步骤操作：


退出交互模式：
在 >>> 后面输入 exit() 然后回车，或者直接按快捷键 Ctrl + Z 再回车。
当你看到左侧变回 PS E:\...> 这种格式时，说明你回到了正常的系统终端。


在正确的环境下输入命令：
确保左侧没有 >>> 后，依次输入：
e:
cd code  # 假设你的代码在 code 文件夹
python test_baidu.py




💡 核心区别（帮你避坑）























环境特征标志作用错误操作终端 (PowerShell)PS C:\Users>运行程序、切换磁盘、管理文件粘贴 Python 代码（报错）Python 交互模式>>>临时测试单行代码逻辑输入 cd 或 python xxx.py（报错）
总结： 运行 .py 文件必须在“终端”里通过 python 文件名 来启动，不能进到 Python 里面去运行它。现在请先 exit() 出来试试。
