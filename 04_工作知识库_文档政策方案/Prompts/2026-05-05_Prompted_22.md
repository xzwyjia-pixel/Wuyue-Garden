## Prompted

很好，你已经成功退出了 Python 交互模式并切回了 E盘。
从 image_1fe4b9.png 的最后两行报错来看，问题在于路径找不到。报错提示 Cannot find path 'E:\code' 以及 can't open file 'E:\\test_baidu.py'。
现在的状况

环境已就绪：你已经在终端环境（PS E:\>）而非 Python 内部。
路径偏差：你直接在 E 盘根目录运行，但系统没在那里找到你的文件。


请执行以下操作来定位文件：
第一步：确认你的文件到底在哪里
在终端输入以下命令并回车：
dir test_baidu.py /s

这会全盘搜索这个文件，并告诉你它在哪个文件夹里。
第二步：进入正确的文件夹
根据上一步搜到的路径，进入对应的目录。

如果搜到在 E:\Playwright\test_baidu.py，你就输入：cd Playwright
如果你不确定文件夹名，可以输入 ls 查看 E 盘下的所有文件夹名称。

第三步：运行脚本
进入文件夹后（左侧显示 PS E:\你的文件夹名>），再次运行：
python test_baidu.py


💡 一个更简单的绝招
如果你找不到文件夹，可以尝试直接把文件从文件夹里拖进 PowerShell 窗口：

在 PowerShell 中先输入 python（后面加一个空格）。
打开 E 盘文件夹，找到 test_baidu.py。
用鼠标按住这个文件，直接拖进黑色的 PowerShell 窗口里。
窗口会自动填充完整路径（例如 python "E:\Downloads\test_baidu.py"），然后直接敲回车即可。

试试这个“拖拽大法”，它能百分之百解决路径找不着的问题。
