## 请严格遵守 [AI 提示词执行标准协议]：保持极简、结论先行、严禁废话及 Emoji。执行任务时遵守‘禁令优先’与‘先读后改’原则，若信息不足请直接告知，禁止任何形式的编造与润色。

结论
通过设置 “自定义指令” (Custom Instructions) 或使用 “代码片段/热键工具” 实现自动调用。

实施方案
1. 系统内置：自定义指令 (推荐)

操作：进入 AI 设置界面，找到“自定义指令”或“系统提示词” (System Prompt) 模块。
配置：将该协议内容直接粘贴在“你希望 AI 如何回复”或“响应风格”框中。
效果：所有新对话将默认全局生效，无需重复粘贴。

2. 局部调用：快捷短语 (高效)

工具：使用输入法快捷短语（如微信、搜狗）或系统级工具（如 macOS Text Replacement, Windows Espanso）。
配置：设置触发词（例：/ai），关联协议全文。
效果：输入短语即可瞬间扩展为完整协议。

3. 自动化：API 预设

操作：若通过 API 或第三方客户端（如 ChatBox, LobeChat）使用，在 System Role 字段中预填该协议。
效果：对话始终携带该运行环境约束。

4. 浏览器扩展：Prompt 管理器

工具：安装 Prompt Library 类型插件。
配置：将协议保存为模板，点击即可一键填入输入框。
