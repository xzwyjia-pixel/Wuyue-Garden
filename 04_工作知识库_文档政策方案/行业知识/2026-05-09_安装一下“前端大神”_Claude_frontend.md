## 安装一下“前端大神”

既然你已经有了 skill-creator 环境并且正在运行 Claude Code，安装“前端大神”（通常指代社区中流传的高级前端工程化与审美增强插件，或者你自己定义的 ui-ux-pro-max-skill 升级版）可以通过以下步骤快速完成。
在你的 E:\MyCodeProjects 环境下，直接在 Claude Code 的 > 提示符后输入：
1. 执行安装指令
# 这种方式会直接利用你现有的 skill-creator 逻辑来生成顶级规范
create_skill frontend-master-pro --description "具备工业级审美、极致性能优化方案及 React/Vue3 高级架构能力的前端大神技能"

如果你是指安装某个特定的远程仓库或工具包，请直接在 Claude Code 里粘贴：
git clone https://github.com/OpenSpec-AI/frontend-master-skills.git ~/.claude/skills/frontend-master


2. 赋予“大神”灵魂：配置审美准则
安装完成后，为了让这个技能真正符合你要求的 “极简主义精密感” (Minimalist Precision) 和 “工业级” (Industrial-grade) 风格，建议你让 Claude 立即更新该技能的 SKILL.md。
你可以直接对 Claude 说：

“请编辑刚刚安装的 frontend-master 技能，加入以下准则：

设计语言：参考 Apple 和工业自动化软件的精密感，拒绝任何冗余装饰。
技术栈：深度优化 Lucide-react 图标映射逻辑，支持语义化文件夹识别。
性能：所有组件必须通过原子化 CSS（如 Tailwind）实现，确保零冗余样式。”



3. 验证安装
安装完成后，你可以通过以下指令查看它是否已经进入了 Claude 的“大脑”：

查看列表：/skills（在 Claude Code 中查看已加载技能）
立即实战：

“使用 frontend-master 技能，帮我重构一下‘语义文件夹图标可视化’项目的前端主界面，要求看起来像是一个精密仪器仪表盘。”




💡 进阶：如果你需要的是全局“前端环境”增强
如果你所谓的“安装前端大神”是指配置一套完整的开发环境（如 uv, pnpm, fzf 等），请直接运行：
# 安装极速前端包管理工具
npm install -g pnpm
# 或者如果你已经装了 uv
uv tool install frontend-cli
