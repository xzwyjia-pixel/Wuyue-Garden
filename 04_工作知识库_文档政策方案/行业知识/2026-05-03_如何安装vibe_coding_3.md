AI 原生编辑器（最推荐的入门方式）\n这类工具直接将 AI 深度集成在代码编辑器中，能够读取你的整个项目背景。\n\nCursor (目前最主流的 Vibe Coding 工具)\n\n安装： 访问 cursor.com 下载并安装。\n用法： 安装后，使用 Cmd + K (Mac) 或 Ctrl + K (Win) 直接输入你的自然语言需求（例如：“帮我写一个极简风格的待办事项网页”），它会自动生成并修改代码。\n\n\nWindsurf\n\n安装： 访问 codeium.com/windsurf 下载。\n特点： 强调“代理（Agent）”能力，AI 不仅能写代码，还能自主运行终端命令。\n\n\n\n\n2. 命令行 AI 代理（高级进阶）\n如果你习惯在终端（Terminal）操作，可以通过命令行安装 AI 代理工具。\n\nClaude Code (Anthropic 官方推出的终端工具)\n\n安装条件： 电脑需安装有 Node.js。\n安装命令：\nnpm install -g @anthropic-ai/claude-code\n\n\n用法： 在项目目录下输入 claude，然后直接用中文下达指令，它会帮你创建文件、调试 Bug 甚至提交 Git。\n\n\n\n\n3. 在线云端平台（无需本地环境）\n如果你不想在本地配置任何环境（如 Python、Node.js），可以直接使用这些 Web 平台：\n\nReplit / Replit Agent： 在浏览器中输入需求，它会自动帮你配置服务器、数据库并一键上线。\nLovable / Bolt.new / v0.dev： 专门针对前端 UI，输入“我想要一个静奢风的个人主页”，它会瞬间生成可运行的页面。\n\n\n💡 Vibe Coding 的核心流程 (The Workflow)\n\n明确意图 (The Vibe)： 不要思考逻辑实现，而是思考结果。例如：“我需要一个能自动记录规则审计日志的工具，界面要像 iOS 一样简洁。”\n对话式构建： 把 AI 当作你的高级程序员，你只需给出反馈（“这里颜色太深了”、“那个按钮点击没反应”）。\n小步快跑： 每次只改一个功能点，确保 AI 没有跑偏。\n\n建议： 如果你是初学者，推荐从 Cursor 开始，因为它对中文支持良好，且界面与 VS Code 一致，上手最快。\n\n---\n*从 Gemini 导出，2026-05*\n\n---\n*从 Gemini 导出 · 分类: 技术开发 · 2026-05*\n"}
