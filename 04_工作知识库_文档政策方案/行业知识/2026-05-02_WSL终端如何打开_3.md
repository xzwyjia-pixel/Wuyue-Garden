## WSL终端如何打开？

既然你在 image_069ff4.png 中已经展示了一个正在运行的终端界面，说明你其实已经打开过它了。但如果你想知道更标准或更快捷的打开方式，可以参考以下几种方法：
1. 通过 Windows 搜索（最直接）

按下键盘上的 Windows 键。
输入 "Ubuntu"（或者你安装的具体 Linux 发行版名称）。
点击搜索结果中的图标即可打开。

2. 通过 Windows Terminal（推荐）
如果你安装了 Windows Terminal（Windows 11 自带，Windows 10 可在商店下载），这是最强大的方式：

打开 Windows Terminal。
点击顶部标签栏旁边的 向下箭头 (∨)。
在下拉菜单中选择 "Ubuntu"。这会像打开浏览器新标签页一样打开一个新的 WSL 环境。

3. 在 VS Code 中直接打开（最适合你的开发流程）
既然你在 image_10985c.png 中正在使用 VS Code，其实没必要切换到外部窗口：

在 VS Code 中按下快捷键：Ctrl + ~（数字 1 左边的按键）。
这会在编辑器下方弹出终端面板。
如果默认显示的是 PowerShell，点击终端右上角的 "+" 旁边的下拉箭头，选择 "Ubuntu (WSL)"。

4. 通过文件资源管理器地址栏（快速定位路径）
如果你想在某个特定的 Windows 文件夹下直接启动 WSL：

在 Windows 文件夹的地址栏点击一下，清空内容。
输入 wsl 然后按回车。
终端会直接打开，并自动进入当前的文件夹路径。


特别提醒
在你的 image_069ff4.png 截图中，终端显示的路径是 /mnt/c/Windows/System32。

建议： 除非是在修改系统配置，否则不要在 System32 路径下进行 AI 项目（如 Hermes 或 "规则甄查-甄先生"）的安装。
正确做法： 打开终端后，输入 cd ~ 回车，回到你 Linux 系统的个人家目录再执行安装脚本。这样可以避免很多不必要的权限问题。
