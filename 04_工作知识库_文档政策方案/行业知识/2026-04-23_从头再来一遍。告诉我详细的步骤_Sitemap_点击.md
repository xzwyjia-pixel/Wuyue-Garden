## 从头再来一遍。告诉我详细的步骤

明白，咱们“清零”重来。
采集视频号后台这类高安全性、需要扫码的页面，必须采用“半自动配合”的策略。以下是为你量身定制的、百分之百能成功的实战操作全流程：

第一阶段：环境准备（扫清障碍）

登录你的新号： 在浏览器正常页面打开 https://channels.weixin.qq.com/platform，扫码登录进去，直到能看到视频管理或者评论界面。
停留在数据页： 比如你想抓评论，就点开“评论管理”；想抓作品数据，就留在“内容管理”。
复制关键网址： 此时，复制浏览器地址栏那个很长的网址（它带有很多身份参数）。


第二阶段：建立“抓取地图”（Sitemap）

打开工具： 按 F12，找到最右边的 Web Scraper 标签。
新建地图： 点击 Create new sitemap -> Create Sitemap。

Sitemap name: 输入 rules_intelligence（只能是字母下划线）。
Start URL: 粘贴你刚才复制的那个很长的登录后网址。


保存： 点击蓝色的 Create Sitemap。


第三阶段：定义“情报目标”（Selector）

添加选择器： 点击那个蓝色的 Add new selector。
设置 ID： 比如你想抓标题，就写 title；抓评论就写 comment。
选择类型： 默认选 Text（采集文字）。
实地圈选（最关键）：

点击 Select 按钮。
此时鼠标回到上方的视频号网页。去点击你想抓的那段文字（点击后会变红/紫）。
如果你想抓一整列（比如一页所有的评论），请勾选 Multiple 复选框，然后依次点击前两个评论，系统会自动识别出整列。
点击 Done selecting!。


保存： 点击底部的 Save selector。


第四阶段：执行与“肉身”破防（执行任务）
这是你之前卡住的地方，请严格执行以下动作：

开始抓取： 点击顶部菜单 Sitemap rules_intelligence -> 选择 Scrape。
调整延迟： 把 Request interval 改成 3000，Page load delay 也改成 3000（给网络留缓冲时间）。
启动： 点击 Start scraping。
肉身破防（重点）：

这时候会弹出一个新窗口。
盯着那个新窗口！ 如果它显示二维码，立刻拿手机扫码登录（或者在手机上点确认登录）。
只要那个小窗口里跳进了视频号后台，机器人就会开始“抠图”取数。


等待： 等小窗口自动关闭，说明任务完成。


第五阶段：情报导出

刷新预览： 回到 Web Scraper 主面板，点击 Refresh。
查看结果： 如果看到表格里有数据了，恭喜你，情报到手！
导出文件： 点击顶部菜单 Sitemap rules_intelligence -> Export data -> 选择 .csv。


💡 给“规则情报员”的独家秘籍：

不要关掉主浏览器： 扫码是在小窗口操作，但主浏览器保持登录状态有助于小窗口快速识别身份。
分段抓取： 视频号后台如果有很多页，Web Scraper 需要设置翻页逻辑（Pagination）。咱们先学会抓“当前这一页”，抓稳了再教你如何自动翻页。

按照这个步骤，特别是第四阶段的“扫码辅助”，你现在尝试操作一下？如果小窗口成功进入了后台，情报就稳了。
