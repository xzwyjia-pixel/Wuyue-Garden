## 对市面上所有的agent和skill做一个详细的调研和对比

这是该主题的研究方案。如果你需要进行更新，请告诉我。
(1) 搜寻并分类当前市面上主流的 AI Agent 框架和平台，包括但不限于 AutoGPT, Microsoft AutoGen, OpenAI Assistants API, LangChain Agents, 以及新兴的自主 Agent 如 Devin 等。
(2) 调研这些平台中技能（Skills）、插件（Plugins）或工具（Tools）的定义方式、获取渠道及生态系统现状（如 OpenAI GPTs, Claude Tools, Google Gemini Extensions）。
(3) 针对每个重点 Agent 平台，详细了解其核心技术特性：
(a) 自主性水平与推理规划能力
(b) 记忆管理机制（长期与短期记忆）
(c) 环境感知与外部 API 调用能力
(d) 多代理协作（Multi-agent collaboration）支持情况
(4) 搜集并对比不同 Agent 系统的性能表现数据、开发门槛、部署成本（如 Token 消耗、订阅费用）以及主要适用场景。
(5) 查找权威科技媒体、研究机构或开发者社区关于 AI Agent 市场的深度报告，获取市场占有率和用户口碑评价。
(6) 调研特定垂直领域的 Agent 产品（如代码助手、自动化营销、智能客服）及其核心竞争力的技能模块。
(7) 对比分析开源 Agent 生态（如 CrewAI, OpenDevin, MetaGPT）与闭源商业生态（如 OpenAI, Google, Microsoft）在定制化能力、安全性和隐私保护方面的优劣。
(8) 综合以上信息，总结当前 AI Agent 和 Skill 生态面临的主要挑战（如可靠性、安全性问题）并分析未来的技术演进趋势。
