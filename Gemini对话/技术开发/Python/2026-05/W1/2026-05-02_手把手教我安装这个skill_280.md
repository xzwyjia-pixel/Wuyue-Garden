## 手把手教我安装这个skill

这个 tutor-skills 插件是一个非常实用的交互式学习工具，特别适合配合你目前正在使用的 VS Code 和 MCP (Model Context Protocol) 环境来提升代码理解力。
由于这是基于 MCP 协议的扩展能力（Skill），安装过程主要分为环境确认、代码获取和配置挂载三个步骤。

第一步：准备运行环境
在安装具体 Skill 之前，请确保你的本地 AI 开发环境已就绪：

Python 环境：确保已安装 Python 3.10 或更高版本。
VS Code：确保你正在使用支持 MCP 协议的编辑器环境。
MCP 依赖：在终端执行以下命令，确保基础包已安装：
pip install mcp



第二步：下载 Skill 源代码
通常这类自定义 Skill 需要存放于你本地的 AI 项目目录中：

在你的常用工作区新建文件夹（例如 my-mcp-skills）。
将该 Skill 的 Python 脚本文件存入此文件夹。如果这是一个标准的开源工具，你可以通过 git clone 获取，或者直接复制 tutor_skills.py 源码文件。

第三步：在 VS Code 中配置挂载
要让 AI 能够调用这个“交互式学习闭环系统”，你需要在 MCP 配置文件中告诉它路径。

打开你的 MCP 配置文件（通常位于 %APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json 或类似的插件路径下）。
在 mcpServers 部分添加以下配置信息：

{
  "mcpServers": {
    "tutor-skills": {
      "command": "python",
      "args": ["D:/你的路径/my-mcp-skills/tutor_skills.py"],
      "env": {},
      "disabled": false
    }
  }
}


注意：请将 args 中的路径替换为你实际存放文件的绝对路径。

第四步：初始化与测试
配置保存后，重启你的 VS Code AI 插件。你可以通过以下指令测试是否安装成功：

初始化知识库：输入指令 tutor-setup: 扫描当前文件夹。AI 会开始将文档或代码库转化为 StudyVault 格式。
开始交互测试：输入 tutor: 针对[某个函数或文档]对我进行测试。
自动模式：系统会自动侦测你的阅读进度，并提供弱点攻克建议。


进阶建议
由于你目前正在进行 Python 代码审计 相关的技术训练，我建议你优先使用 tutor-setup 扫描你正在编写的审计脚本。这样当你遇到复杂的逻辑时，系统可以自动为你生成测试题目，确保你真正掌握了算法背后的风险控制逻辑。
安装过程中如果遇到 ModuleNotFoundError 或权限报错，请随时告诉我具体的报错截图。
