## 手把手教会我如何安装这个skill

安装这个名为 scholar-skill 的工具，通常涉及到将它作为一个 MCP (Model Context Protocol) 技能集成到你的 VS Code 环境（如 Cline 或 Claude Dev 插件）中。
鉴于你已经在配置 VS Code、MCP 和 Ollama 本地环境，以下是手把手安装该技能的步骤：

第一步：准备环境
确保你的本地开发环境已经具备以下基础：

VS Code 已安装 Cline (原 Claude Dev) 插件。
Ollama 正在运行（推荐使用你之前配置的 qwen2.5-coder 模型）。
已安装 Python 3.10+ 或 Node.js（取决于该 skill 的具体实现代码）。

第二步：获取 Skill 源代码
通常这类特定的 skill 是通过 GitHub 仓库或本地脚本实现的：

下载/克隆仓库：将 scholar-skill 的代码下载到你本地的 AI 项目目录中。
安装依赖：

如果是 Python 项目，在终端运行：pip install -r requirements.txt。
如果是 Node.js 项目，运行：npm install。



第三步：配置 MCP 设置文件
你需要告诉 VS Code 里的 AI 助手如何调用这个新技能：

在 VS Code 中打开 Cline 的 Settings (设置)。
找到 MCP Config 部分，点击打开 custom_mcp_config.json 文件。
在 mjs_servers 或 config 中添加该技能的入口。例如（以 Python 版为例）：
"scholar-skill": {
  "command": "python",
  "args": ["/你的路径/scholar-skill/main.py"],
  "env": {
    "OPENAI_API_KEY": "你的密钥" // 如果该技能涉及高 Token 消耗的联网搜索
  }
}



第四步：激活与测试

重启 Cline：保存配置文件后，在 Cline 面板中刷新或重启，你应该能看到 scholar-skill 已变为 Active (激活) 状态。
功能验证：

该工具支持 L1-L3 分级阅读 和长达 2.5 小时的异步任务。
试着输入：“请帮我深度解构这篇论文，使用 scholar-skill 开启 L3 级异步分析”。




💡 特别提醒

Token 消耗：图片中明确提示该工具为“科研专用（高 Token 消耗）”。如果你使用 Ollama 运行本地模型，请确保你的硬件（如显存）足以支撑长时间的推理任务。
防呆机制：由于该 skill 包含“人类确认防呆机制”，在执行 L3 级长任务时，VS Code 可能会弹出确认框，请留意点击“允许”或“确认”。
