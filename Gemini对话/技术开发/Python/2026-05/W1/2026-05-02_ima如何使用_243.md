## ima如何使用

针对您目前正在开发的**“规则甄查 - 甄先生”**项目，我们将“ima”（在此场景下指代您安装的图像识别与自动化工具链）的使用流程拆解为三个阶段。通过模块化配置，您可以避免重复输入路径等前提条件，实现一键审计。

第一阶段：项目结构布局
为了将“前提条件”永久植入软件，建议在 VS Code 中建立如下文件结构：

config.py：存放 Tesseract 路径和违规词库（底层配置）。
zhen_tools.py：存放图像预处理和 OCR 识别逻辑（核心工具）。
main.py：编写具体的业务审计逻辑（启动程序）。


第二阶段：核心代码实现
1. 植入前提配置 (config.py)
在此文件中定义一次路径，全项目生效。
import pytesseract

# 1. 植入 Tesseract 引擎路径
TESSERACT_EXE_PATH = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

# 2. 预设甄先生专属违规词库
FORBIDDEN_WORDS = ['第一', '最', '绝对', '顶级', '赚钱', '100%']

# 3. 自动关联
pytesseract.pytesseract.tesseract_cmd = TESSERACT_EXE_PATH

2. 封装审计工具 (zhen_tools.py)
通过 OpenCV 提升识别精度，将复杂过程打包。
import cv2
import pytesseract
from PIL import Image
import config  # 引用配置

class ZhenAuditor:
    def preprocess_image(self, img_path):
        """图像预处理：灰度化 + 二值化，解决复杂背景识别难的问题"""
        img = cv2.imread(img_path)
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # 灰度化
        _, thresh = cv2.threshold(gray, 150, 255, cv2.THRESH_BINARY) # 二值化
        return thresh

    def ocr_scan(self, img_path):
        """一键扫描并对比违规词库"""
        processed_data = self.preprocess_image(img_path)
        pil_img = Image.fromarray(processed_data)
        text = pytesseract.image_to_string(pil_img, lang='chi_sim') # OCR 识别
        
        # 自动对比风险点
        found_risks = [word for word in config.FORBIDDEN_WORDS if word in text]
        return text.strip(), found_risks


第三阶段：实际业务调用 (main.py)
完成植入后，您在主程序中只需三行代码即可完成审计：
from zhen_tools import ZhenAuditor

# 1. 初始化工具
auditor = ZhenAuditor()

# 2. 执行一键扫描（系统自动完成：洗图 -> 识别 -> 匹配）
content, risks = auditor.ocr_scan('cover.jpg')

# 3. 查看甄先生审计报告
print(f"识别到的内容: {content}")
if risks:
    print(f"🚩 风险提示：包含违规词 {risks}")


💡 使用要点总结

路径中的 r 前缀：在 config.py 中定义路径时，务必使用 r''，以防止 Windows 路径中的反斜杠被识别为转义字符。
图像预处理：针对短视频封面，直接识别效果较差。先进行灰度化和二值化处理（让背景变白、文字变黑），识别精准度可大幅提升。
扩展性：若平台规则更新，您只需修改 config.py 中的 FORBIDDEN_WORDS 列表，无需改动任何核心逻辑。
