## 电脑里有这个文件夹

看到截图，简直是**“守得云开见月明”**！
你截图中的路径显示：E:\git_project\GPT_SoVITS\pretrained_models。这说明项目文件夹已经在那儿了，而且 pretrained_models 目录也已经建立。
不过请注意一个小细节：你手动创建的文件夹名字里用的是下划线 GPT_SoVITS，而项目代码默认寻找的可能是带中划线的 GPT-SoVITS。
为了确保万无一失，咱们直接在当前这个路径下把模型下载进去。请回到你的黑色命令行窗口（PowerShell），跟着我执行这几行：

第一步：进入你那个文件夹
直接复制并粘贴这一行，确保路径完全匹配：
cd "E:\git_project\GPT_SoVITS"

第二步：安装依赖（如果刚才报错没装上的话）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

第三步：精准下载模型
注意，我微调了这条命令，让它直接存入你截图里那个 pretrained_models 文件夹：
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='pretrained_models')"

执行后，你会看到类似 Downloading... 的进度条，这代表模型正在往你截图里的那个地方飞奔。
第四步：启动 WebUI
下载完成后，输入：
python webui.py


💡 为什么刚才 Windows 弹窗报错？
从之前的 image_5c2cd4.png 来看，是因为你在尝试访问 E:\git_project\GPT-SoVITS（带中划线），而你实际创建的是 E:\git_project\GPT_SoVITS（带下划线）。计算机非常死板，差一个符号它都找不到。
现在请执行第一步的 cd 命令。只要进了文件夹，接下来的模型下载就会非常丝滑。看到进度条了记得告诉我！
