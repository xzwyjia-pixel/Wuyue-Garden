## Prompted

看这报错，镜像站 ghproxy.com 此时可能也抽风了（Failed to connect）。别气馁，这在配置 AI 项目时简直是“家常便饭”。
既然镜像站和 GitHub 直连都不给力，我们换一个国内最稳的路径：直接从 码云 (Gitee) 镜像拉取。
请确保你还在 E:\git_project 目录下，依次执行以下经过精密修正的操作：
第一步：换用 Gitee 镜像克隆
这个源在国内几乎秒开，不需要代理：
git clone https://gitee.com/Miranda-is-ready/GPT-SoVITS.git

执行后如果看到 Receiving objects: 100%，就说明我们终于跨过了第一道大关！
第二步：进入目录并安装依赖
克隆成功后，紧接着安装运行环境：
# 1. 进入目录
cd GPT-SoVITS

# 2. 安装依赖（强制使用清华源加速）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

第三步：下载 ModelScope 模型
既然环境和代码都到位了，模型下载绝不会再 404：
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='GPT_SoVITS/pretrained_models')"


💡 为什么刚才镜像站也挂了？
从截图 image_5cb7da.png 来看，ghproxy 这种公益加速站经常会因为带宽超限导致 Could not connect to server。Gitee 是国内的代码托管平台，稳定性极高，作为备选方案最合适。
🚨 避坑指南：

不要合并命令： 像刚才那样一行只跑一个 git clone，跑完再下一行。
确认 (venv)： 你的截图显示开头一直有 (venv)，非常好，请继续保持这个状态，不要关闭窗口。

现在请执行第一步的 git clone。如果这一步成功了，后续就像顺水推舟一样简单了！
