## 如何安装vibe coding

“Vibe Coding” 并不是一个需要安装的单一软件，而是一种由 AI 驱动的新型开发模式。其核心在于“只传达感觉（Vibe）和意图，让 AI 处理代码细节”。
要开始 Vibe Coding，你通常需要安装或配置以下三类核心工具：

1. AI 原生编辑器（最推荐的入门方式）
这类工具直接将 AI 深度集成在代码编辑器中，能够读取你的整个项目背景。

Cursor (目前最主流的 Vibe Coding 工具)

安装： 访问 cursor.com 下载并安装。
用法： 安装后，使用 Cmd + K (Mac) 或 Ctrl + K (Win) 直接输入你的自然语言需求（例如：“帮我写一个极简风格的待办事项网页”），它会自动生成并修改代码。


Windsurf

安装： 访问 codeium.com/windsurf 下载。
特点： 强调“代理（Agent）”能力，AI 不仅能写代码，还能自主运行终端命令。




2. 命令行 AI 代理（高级进阶）
如果你习惯在终端（Terminal）操作，可以通过命令行安装 AI 代理工具。

Claude Code (Anthropic 官方推出的终端工具)

安装条件： 电脑需安装有 Node.js。
安装命令：
npm install -g @anthropic-ai/claude-code


用法： 在项目目录下输入 claude，然后直接用中文下达指令，它会帮你创建文件、调试 Bug 甚至提交 Git。




3. 在线云端平台（无需本地环境）
如果你不想在本地配置任何环境（如 Python、Node.js），可以直接使用这些 Web 平台：

Replit / Replit Agent： 在浏览器中输入需求，它会自动帮你配置服务器、数据库并一键上线。
Lovable / Bolt.new / v0.dev： 专门针对前端 UI，输入“我想要一个静奢风的个人主页”，它会瞬间生成可运行的页面。


💡 Vibe Coding 的核心流程 (The Workflow)

明确意图 (The Vibe)： 不要思考逻辑实现，而是思考结果。例如：“我需要一个能自动记录规则审计日志的工具，界面要像 iOS 一样简洁。”
对话式构建： 把 AI 当作你的高级程序员，你只需给出反馈（“这里颜色太深了”、“那个按钮点击没反应”）。
小步快跑： 每次只改一个功能点，确保 AI 没有跑偏。

建议： 如果你是初学者，推荐从 Cursor 开始，因为它对中文支持良好，且界面与 VS Code 一致，上手最快。
