## 需要

既然你已经跑通了 Playwright 的基础流程，我们可以直接编写一个具备“敏感词扫描 + 自动截图存证”功能的实战脚本。
这个脚本会访问指定网页，检查是否包含你定义的敏感词。如果发现违规内容，它会自动保存网页源代码并截图，这非常符合你作为“规则审计员”的工作场景。
敏感词扫描脚本模版
你可以将以下代码保存为 E:\playwright_test\audit_tool.py：
from playwright.sync_api import sync_playwright
import time

# 1. 定义你的敏感词库
SENSITIVE_WORDS = ["违禁词A", "异常状态", "广告法违规"] 

def run_audit(url):
    with sync_playwright() as p:
        # 启动浏览器
        browser = p.chromium.launch(headless=False)
        page = browser.new_page()
        
        print(f"正在审计页面: {url}")
        page.goto(url)
        
        # 等待页面加载完成（可根据需要调整时间）
        page.wait_for_load_state("networkidle")
        
        # 2. 获取页面全文内容
        content = page.content()
        
        found_words = []
        for word in SENSITIVE_WORDS:
            if word in content:
                found_words.append(word)
        
        # 3. 逻辑判断与存证
        if found_words:
            print(f"【告警】发现敏感词: {found_words}")
            
            # 生成带时间戳的文件名
            timestamp = time.strftime("%Y%m%d_%H%M%S")
            
            # 自动截图存证
            screenshot_path = f"evidence_{timestamp}.png"
            page.screenshot(path=screenshot_path, full_page=True)
            
            # 保存源代码备查
            with open(f"source_{timestamp}.html", "w", encoding="utf-8") as f:
                f.write(content)
                
            print(f"证据已保存至: {screenshot_path}")
        else:
            print("页面审计通过，未发现敏感词。")
            
        browser.close()

if __name__ == "__main__":
    # 在这里输入你想审计的网址
    target_url = "https://www.baidu.com" 
    run_audit(target_url)


如何运行与使用

修改词库：在代码的 SENSITIVE_WORDS 列表中填入你真正关心的关键词。
执行脚本：
在 PowerShell 中确保处于 E:\playwright_test 目录下，运行：
python audit_tool.py


查看结果：如果页面触发了关键词，文件夹里会立刻多出以 evidence_ 开头的长截图和 HTML 源码文件。

进阶建议
由于你之前提到过对微信视频号和抖音算法风险控制的关注，Playwright 的一个强大之处在于它可以模拟手机环境。你只需要在启动时加入设备模拟，就可以审计移动端的页面：
# 模拟 iPhone 13 访问
device = p.devices['iPhone 13']
context = browser.new_context(**device)
page = context.new_page()

这样你就可以用它来检查移动端网页或 H5 页面是否存在违规风险了。你准备先拿哪个类型的页面进行实测？
