## Prompted

从您提供的截图来看，报错信息非常清晰：TesseractNotFoundError。
虽然您已经在 config.py 中写好了路径，但报错提示 ...tesseract.exe is not in your PATH。这通常是因为 main.py 在运行时，由于某种原因没有成功读取到 config.py 里的配置。
请按照以下步骤快速排查并修复：
1. 检查 main.py 的开头（最关键）
请确保您的 main.py 文件的第一行或第二行就包含了 import config。
如果您的 main.py 是这样写的，它才能生效：
import config  # 必须引入这个文件，才会执行里面的路径关联逻辑
from zhen_tools import ZhenAuditor

auditor = ZhenAuditor()
# ... 剩余代码


2. 检查物理路径是否真实存在
请手动打开电脑的资源管理器，粘贴这个路径：
C:\Program Files\Tesseract-OCR
看看里面是否真的有一个叫 tesseract.exe 的文件。

如果文件夹名字叫 Tesseract 而没有 -OCR，或者您安装到了其他盘，请修改 config.py 里的字符串。


3. 终极修复方案：在 zhen_tools.py 里“双保险”植入
如果 import config 还是报错，我们可以直接在工具类里硬编码路径，绕过引用问题。
请打开 zhen_tools.py，修改它的 __init__ 部分：
import pytesseract
import cv2
from PIL import Image

class ZhenAuditor:
    def __init__(self):
        # 直接在这里强行植入路径，确保万无一失
        pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

    # ... 后面的代码保持不变


4. 关于右下角的警告（Environment variable 'Path'）
截图中右下角弹出的黄色警告提示您的系统环境变量中存在非法的引号 "。

这虽然不是导致 Python 报错的直接原因，但它会干扰 VS Code 的插件运行。
建议： 点击那个警告的 “Ignore” 即可，暂时不影响我们运行代码。

修改 zhen_tools.py，直接在 __init__ 里加上那行 pytesseract.pytesseract.tesseract_cmd = ...。
再次在终端输入 python main.py。
