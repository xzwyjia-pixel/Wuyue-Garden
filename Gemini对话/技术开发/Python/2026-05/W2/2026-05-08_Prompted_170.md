## Prompted

即便我们在脚本里强制指定了 TLS 协议，依然出现 unexpected EOF（连接被意外重置），这说明问题出在网络出口的“第一公里”。
这通常是因为中转站的域名在没有正确 Header 或特定 TLS 握手特征时，被你的本地代理软件（如 Clash）或中转站防火墙直接拦截了。既然你想通过程序自动解决，我们需要换一种更底层、模拟程度更高的方式。
核心诊断：为什么 Invoke-RestMethod 失败？
由于 Invoke-RestMethod 使用的是 Windows .NET 栈，它的指纹非常明显。中转站如果拦截了非浏览器指纹，就会直接丢弃连接（产生 EOF）。

极简自动化方案：使用 Python 脚本执行测试与修改
既然你已经在做 AI 审计项目，电脑里肯定有 Python。Python 的 requests 库比 PowerShell 的原生命令对代理和 SSL 的处理更鲁棒。
请将以下代码保存为 fix_and_test.py 并运行：
import json
import os
import requests

# 1. 基础配置
# 请务必在此处填入你真实的中转域名和 Key
BASE_URL = "https://你的中转域名.com/v1"
API_KEY = "你的_API_KEY"
SETTINGS_PATH = os.path.join(os.environ['APPDATA'], 'Code/User/settings.json')

def update_vscode_settings():
    if os.path.exists(SETTINGS_PATH):
        try:
            with open(SETTINGS_PATH, 'r', encoding='utf-8') as f:
                settings = json.load(f)
            
            # 自动化注入配置项
            settings['cline.anthropicBaseUrl'] = BASE_URL
            settings['anthropic.baseUrl'] = BASE_URL
            
            with open(SETTINGS_PATH, 'w', encoding='utf-8') as f:
                json.dump(settings, f, indent=4, ensure_ascii=False)
            print(f"✅ [1/2] VS Code 配置文件已自动更新为: {BASE_URL}")
        except Exception as e:
            print(f"❌ 配置文件修改失败: {e}")

def test_connection():
    print(f"📡 [2/2] 正在测试连接至 {BASE_URL}...")
    headers = {
        "x-api-key": API_KEY,
        "anthropic-version": "2023-06-01",
        "Content-Type": "application/json"
    }
    payload = {
        "model": "claude-3-5-sonnet-20240620",
        "max_tokens": 10,
        "messages": [{"role": "user", "content": "hi"}]
    }
    
    try:
        # 使用 verify=False 彻底绕过 SSL 握手问题 (对应 -k)
        response = requests.post(
            f"{BASE_URL}/messages", 
            headers=headers, 
            json=payload, 
            verify=False,
            timeout=15
        )
        if response.status_code == 200:
            res_json = response.json()
            print(f"🚀 测试成功！模型回复: {res_json['content'][0]['text']}")
        else:
            print(f"⚠️ 连接已建立但返回错误: {response.status_code}")
            print(response.text)
    except Exception as e:
        print(f"❌ 连接失败。报错详情: {e}")
        print("\n💡 建议方案：")
        print("1. 检查你的 Clash/VPN 是否开启。")
        print("2. 尝试在 Base URL 中删除或添加末尾的 /v1。")

if __name__ == "__main__":
    update_vscode_settings()
    test_connection()

为什么这个方案更符合你的需求？

避开 .NET 限制：Python 的 requests 库不会受到 PowerShell 复杂的安全协议栈影响。
真正自动化：运行一次脚本，修改配置和验证连接全部搞定，符合你“减少人工干预”的要求。
支持 Base URL 容错：如果报错 404，脚本会直接输出返回内容，你可以立刻判断是否需要微调 URL。

运行建议

替换变量：在脚本开头填好域名和 Key。
直接运行：在 PowerShell 里执行 python fix_and_test.py。

如果连这个脚本也报 Connection reset，那 100% 是你的本地代理端口没有正确转发流量，或者中转站挂了。既然你平时开发审计工具，这个 Python 脚本也能直接作为你工具里的网络探测模块。
