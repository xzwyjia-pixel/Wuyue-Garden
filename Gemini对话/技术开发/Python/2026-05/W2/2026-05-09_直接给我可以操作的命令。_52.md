## 直接给我可以操作的命令。

为了实现 VS Code（Cline）、PowerShell (Cloud Code) 以及第三方软件（飞书、抖音工具等）的深度联动，你可以直接在 VS Code 的终端或 Cline 的执行模式下操作以下命令。
这些步骤针对你目前在 ThinkPad P15V 上运行的 Python 环境 和 MCP 架构 进行配置。

1. 实现 VS Code 与 PowerShell 的指令联动
要让 Cline 能够直接操作 PowerShell 并在 Cloud Code 中同步，最快的方法是安装 @modelcontextprotocol/server-shell。
在 VS Code 终端执行：
# 1. 进入你的 MCP 配置目录
cd E:\MyCodeProjects

# 2. 安装本地 Shell 控制服务器（需已安装 Node.js）
npm install -g @modelcontextprotocol/server-shell

# 3. 将以下配置手动添加到你的 mcp-config.json 中
# 这将允许 Cline 直接调用 PowerShell 执行 git 或 cloud-code 命令
{
  "mcpServers": {
    "shell": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-shell"]
    }
  }
}

2. 自动化同步命令（防止重复操作）
你可以创建一个专用的同步脚本 sync_task.ps1，让 Cline 在每次更新 task_progress.md 后自动调用：
# 创建并运行此脚本以实现文件与云端的静默同步
$content = @"
git add .
git commit -m "Auto-sync: $(Get-Date -Format 'yyyy-MM-dd HH:mm')"
git push origin master
"@
$content | Out-File -FilePath "./sync_task.ps1" -Encoding utf8

# 以后只需在 Cline 中输入：
./sync_task.ps1

3. 衔接飞书/腾讯会议（API 联动命令）
如果你需要将“规则侦查”的审计结果 推送到飞书，可以使用以下 Python 快捷指令：
# 1. 安装必要的请求库
pip install requests

# 2. 运行一个简单的推送到飞书的测试命令（替换你的 Webhook 地址）
python -c "import requests; requests.post('你的飞书机器人Webhook地址', json={'msg_type': 'text', 'content': {'text': '规则侦查 V2.0 任务已更新'分析已就绪'}})"

4. 联动抖音 Trinity Rae/工具（桌面自动化）
由于抖音的这类软件通常没有公开 API，你需要使用 Playwright 来实现“无缝衔接”：
# 1. 安装自动化驱动
pip install playwright
playwright install chromium

# 2. 使用以下命令启动一个“同步探测”，它可以模拟点击并抓取这些软件的界面信息
# 请确保你的 v_radar_scanner.py 包含针对这些软件 UI 的识别逻辑
python v_radar_scanner.py --target "trinity_rae" --sync-mode


5. 针对 P15V 性能的专属优化命令
你在 Task 2 中提到了多核优化。为了确保联动时不卡顿，建议执行：
# 设置 Python 进程的优先级为“高”，确保在多任务联动时 audit_core.py 不被挂起
start-process python -ArgumentList "audit_core.py" -Priority High

总结操作流：

在 Cline 界面：直接下达“执行 ./sync_task.ps1”来同步进度。
在 PowerShell：保持 mcp_audit_server.py 运行，它会自动处理来自 Cline 的数据并分发到第三方应用。
针对“甄”姓及其他修正：在生成任何报告前，系统会自动检索你的 User Correction Ledger 以确保身份信息准确。
