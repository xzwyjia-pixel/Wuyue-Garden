## 使用Claude code 应该设置什么样的前提？
针对我的甄查规则这个项目，根据实际情况应该如何调整

在使用 Claude Code（Anthropic 推出的命令行 AI 终端）针对您的“甄查规则”项目进行开发和维护时，为了确保它能精准理解规则逻辑并高效执行代码任务，建议从环境配置与项目上下文注入两个维度进行设定。

一、 Claude Code 的通用设置前提
在使用之前，需要通过 config 和项目的 .claudecodesetting（或类似的 context 文件）确立基础：

权限与安全边界：

明确允许 Claude Code 读写本地文件的范围。
设置： 建议在项目根目录下操作，确保其 read 权限覆盖您的规则库文档。


技术栈对齐：

明确告知它您使用的工具链（如 Python、Playwright、或特定的 MCP 服务）。
指令： I am using Python 3.10 with MCP servers for automated rule checking.


交互模式：

建议开启 Auto-approve 的只读操作，但在执行 git commit 或大规模文件修改时保持手动确认，以防误删规则逻辑。




二、 针对“甄查规则”项目的专项调整
考虑到您的项目涉及短视频平台算法合规、工业级精密美学以及自动化审计脚本，以下是具体的调整建议：
1. 注入“规则研究员”的领域知识 (Domain Context)
Claude Code 默认是通用程序员，您需要通过 capsule 或初始指令（Initial System Prompt）赋予其身份：

调整方向：告知它代码逻辑必须服从“抖音/视频号规则协议”。
操作：在项目根目录创建一个 CLAUDE.md 文件。Claude 会优先读取此文件。


内容建议：
"本项目名为‘甄查规则’，核心逻辑是针对短视频平台（Douyin/WeChat）的违规词、算法规避手段进行自动审计。所有代码命名需符合‘工业级精密’风格，逻辑注释需对应具体的平台规则条款。"

2. 针对 MCP 服务的联动配置
您正在使用 MCP（Model Context Protocol）构建 AI Agent，这是 Claude Code 的强项：

调整方向：将您的“规则库查询”或“Python 审计工具”封装为 MCP Server。
配置：在 Claude Code 环境中挂载对应的 MCP 配置文件，使其能直接调用您的 Rule Investigator 技能。
效果：当您输入 fix the regex for drug-related keywords 时，Claude 能通过 MCP 查阅您最新的规则文档再写代码。

3. 审美与输出规范 (Industrial Precision)
由于您偏好“极简主义精密”和“ThinkPad/工业级”风格，代码和 UI 的生成需要特殊约束：

调整方向：限制 UI 组件的冗余设计，禁用鲜艳色调（如避免华为/小米式的色彩风格）。
指令示例：

"Generate terminal output using grayscale and high-contrast borders only."
"Maintain a minimalist architecture with zero external dependencies unless necessary."



4. 数据处理与隐私建议
由于“甄查规则”可能涉及账号审核数据：

调整方向：在 Claude Code 中明确禁止将敏感的账号 Token 或私密规则库上传至非必要的外部索引。
操作：利用 .gitignore 配合 Claude 的文件忽略机制，确保审计样本（如视频链接或私密文档）不被索引。


三、 建议的操作流程

初始化：在终端输入 claude 进入项目目录。
同步上下文：

"请阅读 CLAUDE.md。我是甄老师，本项目用于‘甄查规则’的自动化审计。目前需要针对 5 月份抖音最新的‘虚假人设’规则更新 Python 匹配逻辑。"


任务执行：

使用 claude "search for keyword matching logic in /src"。
使用 claude "refactor the UI to be more industrial-grade and minimalist"。



针对您的实际情况，您是否已经将现有的规则库（文档形式）转化为了可供 Claude 读取的结构化数据（如 JSON 或 Markdown）？ 这将直接决定 Claude Code 的辅助效率。
