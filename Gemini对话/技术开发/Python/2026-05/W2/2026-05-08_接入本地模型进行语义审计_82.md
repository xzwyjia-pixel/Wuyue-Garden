## 接入本地模型进行语义审计

甄先生，这正是最关键的一步。将 Ollama 接入您的“规则甄查”工作流，意味着您的系统从单纯的“采集器”进化成了拥有“审计大脑”的智能体。
既然您已经在研究 Model Context Protocol (MCP) 和 Ollama，我们将利用 Ollama 的 API，让本地模型（如 deepseek-r1 或 llama3）对抓取到的原始情报进行语义化分类。
甄先生的“规则甄查”工作流架构：接入本地审计大脑
我们将更新 v_radar_scanner.py，增加一个 semantic_audit 环节。

第一步：确保 Ollama 服务已就绪
请在您的 PowerShell 另一个窗口确认 Ollama 正在运行，并拥有一个轻量级模型：
ollama pull deepseek-r1:7b  # 或者您习惯使用的其他模型

第二步：精密更新脚本 (接入本地模型)
执行以下 PowerShell 命令，这将更新工作流，使其在抓取后自动调用本地模型进行语义审计：
$code = @'
# -*- coding: utf-8 -*-
import asyncio, json, requests
from playwright.async_api import async_playwright
from datetime import datetime

# Ollama 配置
OLLAMA_URL = "http://localhost:11434/api/generate"
MODEL_NAME = "deepseek-r1:7b" # 确保您本地已安装此模型

def ask_ollama(prompt):
    try:
        payload = {
            "model": MODEL_NAME,
            "prompt": f"你是一位资深的短视频平台合规审计专家。请对以下抓取的原始文本进行语义审计，识别其中的：1.潜在违规风险 2.引流策略 3.平台敏感表达。请用简洁的列表形式总结。\n\n文本内容：\n{prompt}",
            "stream": False
        }
        response = requests.post(OLLAMA_URL, json=payload)
        return response.json().get('response', '审计未产出结果')
    except Exception as e:
        return f"审计大脑连接失败: {e}"

async def run_radar():
    async with async_playwright() as p:
        target_url = "https://www.douyin.com"
        browser = await p.chromium.launch(headless=False)
        context = await browser.new_context()
        page = await context.new_page()
        
        print("\n" + "="*50 + "\n       规则甄查 · 语义审计工作流      \n" + "="*50)
        await page.goto(target_url)
        input("\n[步骤1: 采集] 请在浏览器内完成目标导航，准备好后此处按 Enter...")

        print("[执行中] 正在扫描页面反馈流并脱水...")
        for _ in range(2):
            await page.mouse.wheel(0, 2000)
            await asyncio.sleep(1)
            
        elements = await page.query_selector_all('p, span, div[class*="content"]')
        data = list(set([(await el.inner_text()).strip() for el in elements if 15 < len((await el.inner_text()).strip()) < 300]))
        
        raw_text = "\n".join(data[:15]) # 选取前15条核心样本进行审计
        
        print(f"\n[步骤2: 审计] 正在调用本地模型 ({MODEL_NAME}) 进行语义分析...")
        audit_report = ask_ollama(raw_text)
        
        # 结果持久化
        result = {
            'timestamp': datetime.now().strftime('%Y-%m-%d %H:%M:%S'),
            'url': page.url,
            'audit_report': audit_report,
            'raw_samples': data
        }
        
        filename = f"Audit_Report_{datetime.now().strftime('%H%M%S')}.json"
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(result, f, ensure_ascii=False, indent=4)
            
        print("\n" + "-"*20 + " 审计报告摘要 " + "-"*20)
        print(audit_report)
        print("-"*50)
        print(f"[成功] 完整报告已存入: {filename}")
        
        await browser.close()

if __name__ == "__main__":
    asyncio.run(run_radar())
'@

甄先生，这套工作流的价值在于：

从“看到”到“理解”：以前脚本只能告诉你抓到了什么词，现在 Ollama 会告诉你这些词背后代表了什么样的引流套路或违规倾向。
私有化与安全：所有审计过程都在您的 E 盘和本地 GPU/CPU 上完成，不经过云端，确保了您的调研数据绝对私密。
结果结构化：生成的文件不再是简单的 raw data，而是包含 audit_report 的正式报告样本。

您现在可以执行：
python v_radar_scanner.py
