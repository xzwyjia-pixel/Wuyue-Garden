## Windows如何录制屏幕？

在 Windows 系统中录制屏幕其实非常简单，无需下载第三方软件，系统自带的工具就能搞定绝大部分需求。以下是几种最推荐的方式：
1. 最快捷：Xbox Game Bar（系统自带）
虽然名字叫“游戏栏”，但它几乎可以录制任何非桌面/文件资源管理器的应用程序窗口。

快捷键：按下 Win + Alt + R 直接开始/停止录制。
控制台：按下 Win + G 调出控制面板，你可以调整麦克风开关或查看录制好的视频。
存储位置：默认保存在 此电脑 > 视频 > 捕获 文件夹中。

2. 最灵活：剪切板与截图工具 (Snipping Tool)
如果你使用的是 Windows 11，自带的“截图工具”已经进化到了可以录制任意区域。

快捷键：按下 Win + Shift + S。
操作：在顶部的工具栏中点击摄像机图标，然后用鼠标框选你想录制的区域，点击“开始”即可。
优点：可以只录制屏幕的一小块，非常适合做简单的操作演示。

3. 最专业（进阶）：Microsoft PowerPoint
如果你正在准备 PPT 汇报，可以直接用它录屏：

路径：打开 PPT -> 点击顶部菜单栏的 “插入” -> 选择最右侧的 “屏幕录制”。
优点：录完后视频会直接插入到幻灯片中，你也可以右键点击视频将其另存为 MP4。


💡 避坑小贴士：

无法录制桌面？ Xbox Game Bar 默认不能录制 Windows 桌面或文件资源管理器窗口。如果你需要录制整个桌面的操作，请务必使用 Windows 11 的截图工具 或者第三方软件（如 OBS Studio）。
性能消耗：录制时如果发现电脑变卡，可以检查是否开启了“高帧率录制”，通常 30 FPS 对于普通演示已经足够。

你目前使用的是 Windows 10 还是 Windows 11？不同版本的截图工具功能差异很大，我可以根据你的版本提供更精确的设置建议。
