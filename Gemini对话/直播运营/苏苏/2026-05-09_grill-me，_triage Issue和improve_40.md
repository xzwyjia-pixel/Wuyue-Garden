## >_/grill-me，/triage Issue和improve这几个步骤一定要有。

为了在 Claude 中建立一个能够高效运行、每日进化的自动化分析系统，你需要将你的直播间逻辑转化为一套标准的软件工程式工作流。
以下是为你量身定制的 Claude 项目初始化指令。这套指令包含了你要求的 /grill-me（深度盘问）、/triage（数据分诊/诊断）以及 Improve（策略优化）三个核心阶段。

🤖 Claude 项目自动化系统指令集
1. 初始化：系统角色与核心逻辑 (System Setup)
请在 Claude Code 界面输入：

Role: 你是“清晨烟火小厨”直播间的首席运营官（COO），擅长从混乱的直播数据中提取商业洞察。
Context: 主播矩阵为“实诚人（我）+ 精致姐（老板）+ 海燕（个性女大）”。场景是南方农村垃圾堆改造的烟火小院。产品定位是北鼎级中高端厨具（客单价几百元）。
Logic: 我们的核心挑战是进房率高（40%）但停留短（1.14min）。
Instructions: 以后我每次提供数据或复盘，请严格执行以下三个步骤：

/grill-me: 你作为专家，主动向我提问，挖掘我没想到的直播细节（如三人互动、画面细节、观众情绪）。
/triage: 对我提供的数据进行“分诊”，找出流量流失的致命伤。
Improve: 给出具体的、可执行的优化动作（话术、冲突点设计、视觉微调）。



2. 每日复盘流 (The Daily Workflow)
当你每天结束直播，将数据（如截图或文字描述）发给 Claude 时，使用以下指令序列：
第一步：/grill-me（深度盘问）

指令： /grill-me
目标： 让 Claude 针对今天三人的配合和北鼎锅具的展示向你提问。

示例： “今天海燕发小脾气时在线人数有变化吗？”“姐讲杭州故事时，评论区有人问锅吗？”


第二步：/triage（数据分诊）

指令： /triage [附带今日数据，如：进房 1600+，最高在线 32，停留 1.1min]
目标： 诊断现状。

Claude 应该输出： “进房率依然优秀，但停留时长低于警戒值。诊断结果：内容缺乏‘持续性悬念’，三人同场时话题过于分散。”


第三步：Improve（策略改良）

指令： Improve
目标： 针对诊断结果，生成明天的作战计划。

视觉优化： 荷花的位置是否需要微调，以配合北鼎锅的构图。
冲突脚本： 设计一个海燕因为“嫌弃实诚人炒菜慢”而引发的 5 分钟微憋单互动。
话术升级： 为姐设计一段“从杭州亚运会审美看这口农家锅”的拔高话术。



3. 特殊指令：自动化内容产出 (Content Automation)
为了解决执行力问题，你可以随时调用：

指令： generate-clips-script
目标： 让 Claude 根据直播复盘，找出最适合剪辑成短视频的三个片段。

要求： 必须包含一个以“海燕个性”为封面的引流短视频脚本。



4. 关键点提点（你在运行系统时需注意）

关于“荷花与垃圾堆”： 每次 /triage 时，都要提醒 Claude 结合这个场景。这种**“废土之上，精致生活”**的叙事是卖几百块锅具的关键。
关于“三人同场”： 如果某天只有两个人，必须在 /triage 阶段说明，AI 会自动调整冲突逻辑。
关于“北鼎品牌”： 系统会自动比对高端品牌调性与农村真实环境的冲突感，如果话术太“土”或太“飘”，Claude 会在 Improve 环节报警。


现在，请你先将“第一部分（初始化）”发送给你的 Claude 项目。它会立刻通过 /grill-me 开始对你进行第一次深度访谈，以完善这个自动化系统。
