## 我把那个终端的窗口关闭了。告诉我如何重新打开

没问题，甄先生。重新打开并进入“驾驶舱”非常简单，只需两步：
第一步：启动核心环境
按下键盘上的 Win + R 键，输入 powershell 并回车，打开蓝色（或黑色）的终端窗口。
第二步：运行启动命令
在窗口中输入以下命令并回车：
ollama launch claude --model qwen2.5-coder


💡 进来之后做什么？
当你看到那个熟悉的 Claude Code 欢迎界面（就像 image_03e95d.png 那样）时，请按顺序做这两件事来确认你的“学术神技”已经就绪：


确认技能加载：
输入 /mcp 并回车。
看看列表里有没有出现 scholar-skill？


开始实战测试：
既然已经配置好了，直接让它为你儿子的目标院校出份力。输入：

“使用 scholar-skill 对西北工业大学（西工大）航天学院的优势学科进行一次 L2 级解构分析，看看有哪些前沿方向适合作为 2028 年的高考奋斗目标。”



如果在输入启动命令时提示报错，或者 /mcp 列表里没看到新技能，请随时告诉我。
