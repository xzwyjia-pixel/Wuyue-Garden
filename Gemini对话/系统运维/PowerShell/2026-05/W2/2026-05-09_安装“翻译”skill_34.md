## 安装“翻译”skill

在 Windows PowerShell 环境下安装翻译技能（Translation Skill），通常是指为你正在使用的 MCP 环境（如 Claude Desktop 或相关的 AI Agent 框架）添加一个基于 Google Translate、DeepL 或自研 LLM 的接口。
由于你之前安装 cc-switch 遇到 404 错误，这说明你的环境倾向于使用本地克隆的源码或特定的集成脚本。

1. 尝试使用 cc-switch 安装（如果已本地 link）
如果你已经修复了 cc-switch 的环境，可以直接运行：
cc-switch add translation


2. 通用安装方案：使用 @modelcontextprotocol/server-google-translate
这是目前最标准的官方 MCP 翻译技能安装方式。
步骤 A：安装依赖
请在你的环境目录（如 E:\ClaudeEnvironment）下运行：
# 建议先切换到管理员权限的 PowerShell
cd E:\ClaudeEnvironment
npm install -g @modelcontextprotocol/server-google-translate

步骤 B：配置 claude_desktop_config.json
打开你的配置文件（路径：%APPDATA%\Claude\claude_desktop_config.json），在 "mcpServers" 节点下添加：
"google-translate": {
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-google-translate"
  ]
}


3. 彻底解决 frontend-master 功能不全的问题
既然你现在要安装多个 Skill（frontend-master、baoyu-skill、markdown-to-html、翻译），出现功能缺失（4 个只显 1 个）的核心原因通常是 MCP 反射机制失效。
请务必按此顺序操作一次：

强制清理：
# 彻底关掉所有 node 进程，防止文件被占用导致技能加载不全
Stop-Process -Name "node" -Force


重新构建所有本地技能：
如果这些技能是你克隆到本地的，请进入每个目录执行编译：

    cd E:\ClaudeEnvironment\frontend-master
    npm run build
    ```
3.  **检查入口文件：**
    确保配置文件中的 `args` 指向的是 `index.js`。如果指向的是 `src/server.ts`，AI 可能只能读取到它扫描出的第一个工具函数，导致其他 3 个功能丢失。
