## 帮我写条命令来完成你说的一分钟修复方案

既然你已经安装了 PowerShell 7，我们可以直接用一条命令把你的 E:\ClaudeEnvironment\npm_global 路径永久添加到系统的环境变量中。这样你以后在任何地方直接输入 gsd、opsx 或 ecc 都能直接运行。
请在 PowerShell 7 中复制并执行以下命令：
$targetPath = "E:\ClaudeEnvironment\npm_global"; $oldPath = [Environment]::GetEnvironmentVariable("Path", "User"); if ($oldPath -notlike "*$targetPath*") { [Environment]::SetEnvironmentVariable("Path", "$oldPath;$targetPath", "User"); Write-Host "✅ 成功！路径已添加到环境变量。" -ForegroundColor Green } else { Write-Host "ℹ️ 路径已经存在，无需重复添加。" -ForegroundColor Cyan }

执行后的操作：

重启终端：执行完这条命令后，请关闭当前的 PowerShell 窗口。
重新打开：再次打开一个新的 PowerShell。
验证：输入以下简短的命令，如果能看到输出，说明修复彻底完成：

gsd --version
opsx --version
