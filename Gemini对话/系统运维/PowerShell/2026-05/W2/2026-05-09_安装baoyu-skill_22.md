## 安装baoyu-skill

安装 baoyu-skills 和补全 frontend-master 的功能，实际上是在配置 Claude Code 或 MCP (Model Context Protocol) 环境。
由于这些技能（Skills）通常托管在 GitHub 上，直接使用 npm install 往往会报 404 错误。请按照以下步骤操作：

1. 安装 baoyu-skills (宝玉的技能集)
baoyu-skills 是一系列强大的 AI 增强工具（如：知识漫画生成、小红书卡片、文章配图等）。在 Windows PowerShell 中，最推荐的安装方式是使用 Claude Code 的内置指令：
方案 A：直接在 Claude 终端安装（最推荐）
如果你正在使用 Claude Code 命令行，直接输入：
/plugin install baoyu-skills@baoyu-skills

或者让 AI 自动处理：

"请帮我安装来自 github.com/JimLiu/baoyu-skills 的所有技能。"

方案 B：手动通过 npx 安装
如果你想在本地环境运行，可以使用其提供的脚本：
# 建议先进入你的环境目录，例如 E:\ClaudeEnvironment
npx bun ./scripts/sync-clawhub.sh --all


2. 补全 frontend-master 的其余 3 个功能
frontend-master 通常包含 4 个核心能力：视觉分析、UI 样式自动化、响应式布局生成、以及代码诊断验证。如果你只安装了一个，通常是因为配置文件没写全或者依赖没装完。
操作步骤：


检查 claude_desktop_config.json
这个文件通常位于 C:\Users\你的用户名\AppData\Roaming\Claude\。找到 frontend-master 部分，确保它的 args 指向了正确的入口文件，且没有多余的限制参数。


更新依赖与构建
进入该技能的源码文件夹（你应该在 E:\ClaudeEnvironment 下能找到它）：
cd E:\ClaudeEnvironment\frontend-master
npm install
npm run build

构建过程会重新扫描并导出所有 4 个功能模块。


刷新 MCP 状态

彻底关闭 Claude 桌面客户端（确保后台进程也已结束）。
重启客户端，此时它会重新加载所有导出的 tools。
在对话框中输入 /tools（或点击技能图标），确认是否出现了 4 个功能。




💡 进阶提示：解决“拒绝访问”问题
你在上一次操作中关闭 Listary 失败是因为权限不足。安装 cc-switch 或修改系统级配置时，请务必：

按下 Win + X。
选择 终端 (管理员) 或 Windows PowerShell (管理员)。
在管理员窗口下运行安装命令。
