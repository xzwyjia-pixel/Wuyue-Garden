## 按F12之后，节目没反应。

老甄，别急。F12 没反应通常是浏览器锁了快捷键，或者你当前的窗口焦点没在页面上。咱们工业人讲究排障逻辑，按以下三个步骤强行把它呼出来：
1. 强行呼出“开发者工具”的备选方案
如果 F12 没反应，直接用组合键或鼠标：

组合键： Ctrl + Shift + I (Windows) 或者 Cmd + Option + I (Mac)。
鼠标操作： 在网页任何地方点击鼠标右键，选择最下面的**“检查 (Inspect)”**。

2. 找到 Web Scraper 的位置
呼出黑乎乎的开发者面板后，注意看面板最上方的那一排标签（Elements, Console, Sources...）。

它藏起来了： 标签栏右边有个 >> 符号，点开它，Web Scraper 通常就在下拉菜单里。
位置调整： 如果面板在右边太挤，点面板右上角的三个点，选“Dock side”把面板放到屏幕下方，这样看采集地图更清楚。

3. 如果还是看不见标签

检查安装： 回到扩展程序页面，确认 Web Scraper 的开关是开启状态。
刷新页面： 必须先开开发者工具，再刷新一下网页，插件才能加载进去。


快速避坑指令：
老甄，你现在打开的是网页版视频号/抖音吗？必须在网页端操作。
一旦你看到面板里出现了 Web Scraper 这个词，第一步先点 Create new sitemap。
现在面板出来了吗？只要面板出来了，我就教你写那行最关键的选择器代码。
