## 告诉我怎么发指令

甄先生，既然您的本地“大脑” qwen2.5-coder:7b 已经成功入驻，现在您可以直接在 VS Code 左侧的 Cline 对话框中输入指令了。
作为“规则情报局”的负责人，您的指令应当体现出您一贯的“极简精确”风格。以下是几种推荐的发指令方式：
1. 基础任务指令（直接下达命令）
您可以直接告诉 Agent 您想做什么，它会利用本地显存进行计算，不消耗任何费用。

范例： “帮我写一个 Python 脚本，读取本地的 blacklist.txt 文件，并检查我提供的文案中是否包含这些违规词。”

2. 角色设定指令（增强专业性）
由于您正在运营 “规则甄查-甄先生” 品牌，您可以给 Agent 设定一个特定身份，让它的回复更符合您的专业背景。

范例： “你现在是‘规则情报局’的技术专家。请基于我 8 年在 Siemens 和 ABB 的项目管理逻辑，为我规划一套自动化的社交平台合规检测流程。”

3. MCP 技能开发指令（进阶操作）
如果您想让 Agent 拥有更强的功能（比如直接操作您的本地文件或数据库），您可以要求它编写 Skill。

范例： “请帮我编写一个符合 MCP 协议的 Python 工具，用于自动整理我在调研中发现的短视频平台风险控制规则。”

发送指令的小贴士：

保持后台运行：发送指令时，请确保那个显示 ollama serve 的 PowerShell 窗口处于开启状态。
点击 Done 确认：在 Cline 的设置界面点击 “Done” 按钮，确保它已经切换到了 Ollama 模式。
中文支持：您下载的 Qwen 模型对中文语境理解极佳，您可以直接使用自然流利的中文进行沟通。

现在，您可以试着输入：“你好，我是甄先生。请基于‘规则情报局’的项目定位，为我写一段开场白代码。” 看看它的反应！
