/config

2. 手动“焊死”配置文件
如果界面操作已经失效，我们要去改它的“出厂设置”。请在您的 Windows 资源管理器中打开这个文件（或者直接在 VS Code 里打开）：
文件路径： C:\Users\think\.claude-code-config.json
如果找到这个文件，请将其中的 "model": 字段手动修改为您的供应商确定的 ID（通常是 claude-3-5-sonnet 或供应商指定的特定字符串）。
