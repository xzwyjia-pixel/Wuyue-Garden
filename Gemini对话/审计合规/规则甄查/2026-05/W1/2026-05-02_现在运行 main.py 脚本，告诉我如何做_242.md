## 现在运行 main.py 脚本，告诉我如何做

既然您已经完成了环境配置和文件编写，现在运行 main.py 只需要最后临门一脚。作为一名有项目管理经验的专业人士，您可以按照以下标准流程在 VS Code 中启动您的审计工具：

第一步：检查文件位置（确保“全员就位”）
在运行之前，请确保您的 VS Code 左侧文件树中，这四个文件都在同一个文件夹（项目根目录）下：

config.py（配置文件）
zhen_tools.py（工具类）
main.py（启动脚本）
cover.jpg（关键： 找一张您要测试的短视频封面图，改名为这个名字放进去）


第二步：启动运行（三种方式）
方式 1：使用 VS Code 界面（最直观）

在左侧文件栏点击打开 main.py。
点击编辑器右上角的 “三角形播放图标” (Run Python File)。

方式 2：使用快捷键

点击选中 main.py 的代码区域。
按下键盘上的 F5 键（或者 Ctrl + F5 直接运行不调试）。

方式 3：使用终端（最专业）

在 VS Code 下方找到 终端 (Terminal) 窗口。
确认路径显示为您的项目文件夹。
输入以下命令并回车：
python main.py




第三步：查看输出结果
如果一切正常，您会在终端看到类似这样的“甄先生审计报告”：

--- 甄先生规则甄查报告 ---
识别内容: [提取出来的封面文字...]
🚩 风险预警：检测到违规词 ['最', '第一']
（或者显示：✅ 合规通过）
