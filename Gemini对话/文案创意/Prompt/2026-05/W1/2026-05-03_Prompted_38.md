## Prompted

就差最后一步了！在这个页面里，请找到 “扩展程序选项”。
根据你提供的截图，请向下滚动一点，找到 “网站设置” 下方的图标：
1. 点击进入设置页
在截图中，请点击 “网站设置” 右侧那个带有 右上角小箭头 的方框图标（或者是紧随其后的“扩展程序选项”链接）。这会打开 MarkDownload 真正的配置后台。

2. 填写 API Key
进入那个新页面后：

在左侧导航栏找到 Obsidian Settings。
在右侧找到 Obsidian API Key 输入框。
将你从 Obsidian 插件里复制的 Key 粘贴进去。


3. 处理“连接不安全”警告（关键）
填好后，你会看到 API Key 下方有一个测试按钮或服务器地址（通常是 [https://127.0.0.1:27124](https://127.0.0.1:27124)）。

点击那个链接。
浏览器会显示“您的连接不是私密连接”。
不要关闭！ 点击页面上的 “高级” -> “继续访问 127.0.0.1（不安全）”。
只要看到页面出现 {"status":"OK"}，就说明握手成功。


4. 保存
回到 MarkDownload 的设置页面，点击最底部的 Save。
现在，你之前的那个“Please configure your Obsidian API key”红色报错就会消失，紫色按钮就能正常工作了。
