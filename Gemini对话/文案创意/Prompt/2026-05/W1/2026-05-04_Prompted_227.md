## Prompted

这是因为 PyPI 官方库中目前没有名为 minimax-sdk 的包。MiniMax 的官方 Python SDK 实际上使用的是另一个名称。
请尝试执行以下命令进行安装：
pip install minimax-api


常见问题排查
如果安装 minimax-api 后仍有疑问，可以按照以下步骤操作：

检查包名： 确认是否为最新的官方推荐名称，有时开发者会直接使用 requests 库调用 RESTful API 而不使用 SDK。
升级 pip： 确保你的 pip 版本是最新的，以免因版本过旧无法索引新包。

运行：python -m pip install --upgrade pip


网络问题： 如果你在国内环境，建议切换至清华源或阿里源尝试：

运行：pip install minimax-api -i [https://pypi.tuna.tsinghua.edu.cn/simple](https://pypi.tuna.tsinghua.edu.cn/simple)



后续建议
既然你正在构建基于 Python 的审计工具并使用 MCP 环境，建议直接查看 MiniMax 开放平台的官方文档，获取最新的调用示例代码。通常直接使用 openai 的 Python 库并修改 base_url 也是一种非常流行且兼容性更好的接入方式。
