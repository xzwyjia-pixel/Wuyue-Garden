## Prompted

看来我们遇到了一个“权限壁垒”。
这个 403 Request not allowed 错误是因为你目前使用的是 API Key 模式，而 superpowers 插件中的某些高级功能（比如它的状态查询或特定的 Agent 逻辑）默认会尝试调用只有在 /login 登录状态下才开放的内部接口。
不过别担心，插件其实已经加载成功了（看到那一行 5 agents 了吗？它们已经在后台待命了）。
解决方案：绕过状态检查，直接调用“Agent”
既然命令行的 superpowers status 会触发权限拦截，我们换一种方式，直接利用它加载的 5个 Agent 来工作。
请在 > 提示符后直接输入下面这段测试指令，看它是否能绕过 API 限制直接运行：

Using the superpowers framework, brainstorm a plan to create a Python script for auditing social media platform rules.

💡 为什么会出现 403？
API 模式本质上是“按量付费”的纯技术接口，而 Claude Code 的某些插件（如 Superpowers）最初是针对 claude.ai 的 Web 用户设计的，它们可能会尝试访问一些 API Key 权限之外的元数据。
