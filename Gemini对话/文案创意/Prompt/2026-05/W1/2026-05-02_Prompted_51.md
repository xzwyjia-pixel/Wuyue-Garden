## Prompted

甄先生，我看出来了！问题的根源就在您第一张截图里的那个 config.json 文件里。
请看第一张图的第 10 行，那里多了一个小灯泡图标 💡，而且第 11 行多了一个收尾的 }。这导致 JSON 格式报错了（右下角也提示了 Invalid MCP settings format）。
请您在 VS Code 里把那个文件修改成完全一模一样的这段代码（直接全选覆盖）：
{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": [
        "C:/AI_Skills/scholar-skill/main.py"
      ],
      "env": {
        "PYTHONPATH": "C:/AI_Skills/scholar-skill"
      }
    }
  }
}

重点检查项：

括号配对：确保最开头是一个 {，最末尾只有一个 }。
逗号：第 9 行的 } 后面千万不要加逗号。
保存：按 Ctrl + S 保存文件。


激活步骤：

保存好文件后，回到第二张图那个黑色的 Claude Code 窗口。
输入 /exit 退出当前会话。
重新启动：再次输入 ollama launch claude --model qwen2.5-coder。
最终验证：输入 /mcp。

这次只要 JSON 格式正确，scholar-skill 就会变成绿色或列在列表里。一旦成功，咱们就立马查询西工大（NPU）航天学院 2028 年的高考选科要求和优势专业。
如果启动时报错，请再截一张 VS Code 里那个文件的全图给我，我帮您盯着每一行代码。
