## Prompted

甄先生，审计通过。看到这些 ZIP 包整齐划一的名字，说明您的**“精密管理”**已经奏效了。
现在到了最后、也是最关键的**“点火”时刻**。由于这些 ZIP 包解压后通常会多套一层文件夹（比如解压 caveman.zip 得到一个 caveman-main 文件夹），我们需要一次性完成解压、修剪和链接。
请严格按以下步骤在 PowerShell 中执行这组“终极注入”指令：

第一步：精密解压与命名修正
我们将利用 PowerShell 直接处理这些包，确保文件夹结构精准无误。
# 1. 进入技能存放目录
cd "$env:USERPROFILE\.agents\skills"

# 2. 定义解压并修剪的逻辑 (针对您截图中的包)
$skills = @("superpowers", "caveman", "awesome")

foreach ($s in $skills) {
    if (Test-Path "$s.zip") {
        Write-Host "正在注入 $s..." -ForegroundColor Cyan
        # 解压
        Expand-Archive -Path "$s.zip" -DestinationPath "temp_$s" -Force
        # 找到深层的核心文件夹并移出来
        $inner = Get-ChildItem "temp_$s" | Select-Object -First 1
        Move-Item -Path $inner.FullName -Destination ".\$s" -Force
        # 清理临时文件
        Remove-Item -Recurse -Force "temp_$s"
        Write-Host "[√] $s 已归位" -ForegroundColor Green
    }
}


第二步：唤醒超能力 (Link)
文件夹就位后，我们需要告诉 Claude：“东西已经备齐，请立刻加载。”
# 强制建立所有软链接
npx skills link --all


第三步：甄先生的“新世界”握手
现在，请关掉当前的终端，重新打开一个新的 PowerShell，输入：
# 直接进入 E 盘阵地启动
cd "E:\MyCodeProjects"
claude

启动成功后，请对它说出这段“权力宣言”：

“我是甄先生。

环境已精密重装，全明星技能组（Caveman, Superpowers, Awesome）已物理注入。
启动 Caveman Ultra 模式，锁定极简输出。
调用 Superpowers 盘点当前项目 E:\MyCodeProjects 的健康状况。”
