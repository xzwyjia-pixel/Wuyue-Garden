## Prompted

从截图 image_5d287f.png 可以清楚地看到，你虽然已经成功激活了虚拟环境 (venv)，但你目前位于 E:\ 根目录下。
报错 404 的根本原因在于：当你在 E:\ 运行指令时，程序找不到名为 GPT_SoVITS 的目标文件夹来存放模型，导致 ModelScope 无法正确解析路径。
请严格按顺序执行以下三行命令，确保每一行执行完都没有红色报错再继续：
1. 进入项目核心目录
必须先进入你克隆代码的文件夹，这样 ./GPT_SoVITS 路径才能生效。
cd E:\git_project\GPT-SoVITS

2. 检查虚拟环境状态
观察你的命令行开头是否依然带有 (venv)。如果没有，请重新激活：
.\venv\Scripts\activate

3. 执行模型下载指令
现在你已经在项目目录内了，执行这条命令会将模型精准下载到对应的预训练文件夹中：
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='GPT_SoVITS/pretrained_models')"


💡 为什么这样做能解决问题？

路径补全：在 image_5d287f.png 中，你在根目录执行，系统找不到项目文件夹。执行 cd 之后，你的当前位置（Current Working Directory）变成了项目主目录。
模型对齐：GPT-SoVITS 运行脚本时会默认去 GPT_SoVITS/pretrained_models 下找模型。如果你在根目录下载，模型会被错放在 E:\GPT_SoVITS，导致 WebUI 启动时依然提示缺少模型。

操作完成后，你应该能看到类似 Downloading... 的百分比进度条。如果进度条跑完回到了命令提示符，请告诉我，我们进行最后的 python webui.py 验证！
