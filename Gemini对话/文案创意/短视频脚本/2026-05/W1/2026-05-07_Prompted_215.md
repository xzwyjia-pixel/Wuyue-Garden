## Prompted

甄先生，我从你的最新截图（image_fbcb93.png）中看出了问题所在：你目前打开的是 VS Code 全局的设置搜索界面，而 Cline 的配置面板并不在这里。
在 VS Code 的全局设置里搜“API Provider”只会跳出一些不相关的插件选项。
真正的“精密配置”路径
请直接看 VS Code 窗口的最左侧那排狭长的图标栏，按照以下步骤操作：

点击 Cline 图标： 找到那个正方形机器人头像（也就是你安装 Cline 插件后出现的图标），点击它。
寻找侧边栏齿轮： 点击图标后，左侧会弹出一个专门的 Cline 对话面板。在这个面板的右上角，有一个微小的齿轮图标（Settings），点击它。
下拉菜单选择： 点击那个齿轮后，面板中央会弹出一个下拉菜单，第一项就是 API Provider。

在这里选择 Anthropic。
在下方出现的输入框里粘贴你的 sk-ant-api03-... Key。




💡 为什么之前的操作找不到？
VS Code 的架构非常精密，它将“编辑器基础设置”和“插件核心功能”分开了：

你刚才打开的 Ctrl + , (Settings) 是改字体、颜色等基础参数的。
Cline 的 API 配置 属于它的“引擎核心”，必须在它自己的机器人面板里设置。


配置成功后的第一件事
一旦你填好 Key 并点击最下方的 Done，你就会回到聊天界面。这时，你可以直接输入我们之前商定的**“超级规则”**，把它的审计能力激活：

“请作为我的首席规则审计官。我已经通过 API Key 成功激活。
请遵循以下工业级执行标准：

Brainstorming: 在动工前，先给我 3 个步骤的逻辑对齐。
TDD 模式: 先写针对风险词的测试用例，再写代码。

收到请确认，并开始帮我规划那个敏感词扫描脚本。”

甄先生，如果你在左侧侧边栏找不到那个机器人图标，或者点击后右上角没看到齿轮，请给我发一个 VS Code 的全屏截图，我直接指给你看！
