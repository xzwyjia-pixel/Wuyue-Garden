## Prompted

看到截图了，这是一个非常典型的**“误会”**。
在 image_0461b7.png 中，你是在 ollama run qwen2.5-coder 的模型对话框里输入了命令。那个 >>> 符号表示你正在直接和 AI 模型聊天，而 AI 模型并不认识 ollama launch 这种系统命令。

正确的操作步骤
我们需要退出“聊天模式”，回到“系统命令行”模式。
1. 退出当前的 AI 对话
在当前的窗口中输入 /exit 然后按回车，或者直接按 Ctrl + C。
直到你看到路径显示为 PS C:\Windows\System32>，这才是真正的系统命令行。
2. 正确启动命令
在看到 PS C:\Windows\System32> 后，请再次输入你在 image_04619b.png 界面中看到的启动命令：
ollama launch claude


接下来如何安装 Skill？
一旦助手成功启动，你就可以开始正式挂载 scholar-skill 了。以下是你的行动指南：
第一步：找到并解压 Skill 文件

确保你已经把 scholar-skill 的文件夹放在了一个好找的地方，比如 C:\AI_Skills\scholar-skill。

第二步：配置 Cline 的 MCP 路径

打开 VS Code。
点击 Cline 插件图标 -> 点击齿轮图标 (Settings)。
点击 MCP Config，这会打开 cline_mcp_settings.json。
在里面添加这段配置（注意修改你的实际路径）：

{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": ["C:/AI_Skills/scholar-skill/main.py"] 
    }
  }
}

第三步：安装 Python 依赖

回到 PowerShell（确保不是在 AI 聊天模式下），进入技能目录：
cd C:\AI_Skills\scholar-skill
运行：pip install -r requirements.txt


💡 甄先生的小贴士

Token 消耗提醒：图片 image_054a58.png 提到这是“科研专用（高 Token 消耗）”。如果你之后使用的是联网模型（如 Claude 3.5 Sonnet），请留意 API 的额度。
异步任务：如果启动了 L3 级的 2.5 小时长任务，请确保电脑不要进入深度休眠，否则 Python 脚本可能会中断。

现在请尝试 /exit 退出模型对话，并在系统命令行运行 launch 命令。如果还是报错，请把报错信息发给我！
