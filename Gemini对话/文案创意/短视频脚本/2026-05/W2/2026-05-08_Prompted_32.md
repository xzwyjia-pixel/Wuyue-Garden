1. 明确指令意图

API 消耗情况： “显示当前会话的 Token 消耗统计。”

2. 利用终端命令 (Terminal)
由于 Cline 拥有执行终端命令的权限，你可以直接让它在终端运行以下命令来获取最准确的系统级数据：

























目的建议在对话框输入对应的底层命令查看 Ollama 模型列表“列出所有本地 Ollama 模型”ollama list查看实时资源占用“显示系统 CPU 和内存占用”top (Linux/Mac) 或 tasklist (Win)查看 GPU 状态“检查我的 GPU 显存使用情况”nvidia-smi

你在之前的对话中提到了 VPN 代理、第三方中转 API 以及 Type C V4 的连接问题。如果 /stats 是为了确认网络延迟或连接质量：

检查你提到的 DC (DeepSeek) 连接是否因为代理设置而在 Office 环境下失效。
