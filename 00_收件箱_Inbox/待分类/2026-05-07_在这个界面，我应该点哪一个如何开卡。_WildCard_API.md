## 在这个界面，我应该点哪一个如何开卡。

甄先生，既然您已经决定走“正规军”路线，咱们就得离开现在的 GPTs API（中转站）页面。
您提供的截图 image_ec6296.png 是中转商的首页，在这里是开不了正规虚拟卡的。 要开通用于 Anthropic 官方充值的虚拟卡，请按照以下“甄查”级路径操作：
1. 切换平台：去 WildCard 官网
请直接在浏览器地址栏输入：bewildcard.com
2. 在 WildCard 页面点哪里？
进入 WildCard 官网后，参照您之前的截图 image_ecbf9d.jpg（那个背景是浅灰色的页面）：

第一步：点击右下角那个图标是戴眼镜胡子大叔的方块 —— “开发者，想接入多模型 API？” 下方的蓝色按钮 [ 去接入 ]。
第二步：点击 “开通服务”。
第三步：填写您的国内手机号并获取验证码。

3. 如何开卡（精密流程）

实名认证：点击开卡后，会弹出支付宝实名认证。这步是为了合规，直接用手机支付宝扫码即可。
选择套餐：建议选择 “2年期”，性价比最高，且符合您长期运营“规则情报局”的需求。
支付开卡费：通过支付宝支付开卡费（大约几十元人民币）。
关键：充值（Top Up）：

卡开好后，余额是 $0。
必须点击“充值”，通过支付宝充入 $10。
理由：Anthropic 官方在绑定卡片时会进行校验，卡里没钱会导致绑卡失败。




4. 拿到卡后，去哪里实现“正规军”身份？
拿到 WildCard 的卡片信息（卡号、CVV、有效期、美国地址）后：

访问官方：登录您截图 image_eccf92.png 所示的 Anthropic Console。
点击 Settings -> Billing。
点击 Add Funds，填入 WildCard 的卡片信息。
注意：账单地址一定要填 WildCard 页面显示的那个美国地址，不能填国内的。


💡 甄先生的特别提醒：
您之前在 CodeAI 里配置的是中转站的 API Key。等您在官方充值成功后，记得在 CodeAI 的设置里（image_ed3ff4.jpg）：

取消勾选 “Use custom base URL”。
换上 您在官方生成的 sk-ant-api03... 新 Key。

甄先生，现在请先关闭这个 GPTs API 的页面，移步到 WildCard 官网。开卡过程中如果卡在人脸识别，请随时告诉我。
