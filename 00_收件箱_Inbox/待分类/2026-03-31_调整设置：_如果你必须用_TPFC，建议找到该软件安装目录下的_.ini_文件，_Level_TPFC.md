## 调整设置： 如果你必须用 TPFC，建议找到该软件安装目录下的 .ini 文件，适当调高风扇转速切换的温度点（例如将最高档设在 80°C 以上）。
这个操作步骤，请给出每一步的具体操作

要调整 TPFanControl (TPFC) 的温度阈值，你需要编辑其配置文件。这个文件通常具有系统权限保护，所以请按照以下步骤操作以确保修改生效：
第一步：彻底退出软件
在修改配置文件之前，必须先关闭正在运行的程序，否则修改可能无法保存或生效。

在任务栏右下角的系统托盘图标上右键点击 TPFC。
选择 Exit（退出）。

第二步：以管理员身份打开记事本
因为 TPFC 通常安装在系统盘（C盘），直接修改文件会提示“拒绝访问”。

点击任务栏的搜索框（或按 Win + S）。
输入 “记事本” 或 “Notepad”。
在搜索结果上点击右键，选择 “以管理员身份运行”。

第三步：定位并打开 .ini 文件

在记事本中，点击左上角的 文件 (File) -> 打开 (Open)。
在弹出的窗口地址栏中输入（或手动找到）安装路径，通常是：
C:\Program Files\TPFanControl
注意： 将窗口右下角的文件类型从 *.txt 切换为 “所有文件 (.)”。
找到名为 TPFanControl.ini 的文件，双击打开。

第四步：修改温度曲线（Smart Mode）
在记事本中按 Ctrl + F 搜索关键词：Level=。你会看到类似下面的一段代码：
// 示例：Level=温度 档位
Level=60 0     // 低于60度，风扇停转
Level=65 1     // 65度，风扇1档（低速）
Level=75 3     // 75度，风扇3档（中速）
Level=80 7     // 80度，风扇7档（最高速）
Level=90 64    // 90度，交给BIOS控制（极端安全保护）

具体操作：

根据你的需求，调高数值。比如你希望风扇不要太早进入最高速，可以将 Level=80 7 改为 Level=85 7。
如果你觉得 60 多度时风扇太响，可以把 Level=60 1 调高到 Level=68 1。

第五步：保存并重启软件

修改完毕后，点击 文件 (File) -> 保存 (Save)。
关闭记事本。
重新运行 TPFanControl 软件。
确保软件界面上的模式选在 Smart，它就会按照你刚刚设置的新规则运行了。


💡 小贴士

备份： 在修改前，建议把原文件复制一份存到桌面，万一改乱了可以随时恢复。
不要设得太极端： 建议最高档位（Level=64 或 Level=7）设置在 85°C 以内，以防长时间高热损坏电脑硬件。
64 这个数值： 在 TPFC 中，档位设为 64 代表将控制权交还给电脑 BIOS，这通常是作为最后一道高温防线。
