## 我的电脑现在找不到VScode软件了。我想用，怎么办

找不到 VS Code 可能是因为快捷方式丢失，或者软件被安装在了非标准路径下。你可以按照以下步骤尝试找回或重新安装：
1. 尝试全局搜索
按下键盘上的 Win + S（或点击任务栏搜索框），输入 VS Code 或 Visual Studio Code。

如果能搜到，右键点击它选择“打开文件所在的位置”，然后把执行程序右键发送到桌面快捷方式。

2. 检查默认安装路径
VS Code 通常有两种安装方式（用户版或系统版），你可以直接复制以下路径到文件夹地址栏中查看：

用户版（最常见）：
%LocalAppData%\Programs\Microsoft VS Code
系统版：
C:\Program Files\Microsoft VS Code


进去后找 Code.exe，双击看能不能运行。

3. 通过命令行启动
按下 Win + R，输入 cmd 回车。在黑色窗口里输入 code 然后按回车：

如果 VS Code 启动了，说明软件还在，只是快捷方式没了。
如果提示“不是内部或外部命令”，说明安装路径可能不在系统变量里，或者软件已被卸载。

4. 重新安装（最彻底的办法）
如果上述方法都找不到，最简单的建议是重新下载安装。即便之前有配置和插件，重新安装通常也会自动关联并恢复。

官方下载地址： https://code.visualstudio.com/
安装建议： 下载 System Installer (64 bit) 版本，安装时勾选“添加到 PATH”以及“创建桌面快捷方式”，这样以后找起来方便。


提示： 如果你是为了同步工作环境或开发项目，建议安装后登录账号开启 Settings Sync（设置同步），这样下次即便换了电脑或软件丢了，你的插件和快捷键也能一键找回。
