## Add new selector这个按钮出来了，我也点击了。

恭喜！你终于推开了这扇大门。
点击 Add new selector 之后，你会看到一个配置表单。这是整个采集最核心的步骤，就像是在告诉机器人：“在这个网页上，帮我把那一块文字抠出来”。
为了让你第一次尝试就能成功，我们先做一个最简单的实验：采集网页顶部的某个标题或文字。
按照以下步骤填写表单：

ID: 输入 test_title（这是你给这列数据起的名字）。
Type: 默认是 Text（采集文字），先不要改它。
Selector (最关键的一步):

点击那一横行右边的 Select 按钮。
这时你的鼠标变成了一个“探测器”，网页背景会变红或变绿。
去网页上移动鼠标，直到你想采集的那段文字（比如“视频号助手”或者某个视频标题）被红色框圈住。
点击它，框会变成紫色。
点击 Web Scraper 面板上的 Done selecting!。


Save Selector: 点击最下方的蓝色按钮保存。


保存成功后，如何看到结果？
你现在只是给机器人下了个单，还没让它干活。

点击顶部菜单栏的 Sitemap (shipinhao)（那是你的地图名字）。
在下拉菜单里选择 Scrape。
点击弹出窗口里的 Start scraping。
这时候会弹出一个新窗口（那是机器人在模拟你的行为），千万别关掉它，等它自己消失。
消失后，点击面板上的 Refresh，你就能看到刚才抓到的那行字出现在表格里了！


规则情报员的特别嘱咐：
既然你现在的目标是运营“规则情报局”，那么采集视频号数据时，你最想拿到的应该是评论区的高频词或者竞品的爆款标题。
如果你现在已经扫码进入了后台，你想先试着抓取哪块数据？

是抓取视频列表的标题？
还是抓取单篇视频的评论内容？

告诉我你的目标，我直接给你对应的数据结构建议（比如如果是评论，Type 可能要选 Element scroll downstream 才能抓到滚动加载的内容）。
