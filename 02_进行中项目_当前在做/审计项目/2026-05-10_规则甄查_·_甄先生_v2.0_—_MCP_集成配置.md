# 规则甄查 · 甄先生 v2.0 — MCP 集成配置

## Claude Desktop MCP 配置

将以下配置加入 Claude Desktop 的 `claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "zhen-audit": {
      "command": "python",
      "args": ["E:/MyCodeProjects/mcp_audit_server.py"]
    }
  }
}
```

配置路径（Windows）：`%APPDATA%\Claude\claude_desktop_config.json`

## 可用工具

### 1. audit_content (v1.0 兼容)
审计短视频文案，检测违禁词与营销诱导词，返回风险列表与合规改写建议。

**参数：** `text` (string) — 待审计的文案内容

**示例：**
> "帮我审计这段文案：[文案内容]"

### 2. audit_dual (v2.0 核心) ⭐
**红绿灯双向导航审计。** 同时输出：
- 🔴 **红灯风险点** — 违禁词、营销诱导、规范建议三级风险
- 🟢 **绿灯激励点** — 长效价值、实证原创、合规创新三级激励
- 📊 **政策契合度** — 原创度/真实性/价值性/合规性四维评分
- 💡 **优化建议** — 可执行的行动清单

**参数：** `text` (string) — 待审计的文案内容

**示例：**
> "用双向导航审计这段文案：这是全网第一的赚钱秘籍..."

### 3. policy_check (v2.0 新增)
**政策契合度专项评估。** 从原创度、真实性、价值性、合规性四个维度评分，判断内容与 2026 平台政策的契合程度。

**参数：** `text` (string) — 待评估的文案内容

**示例：**
> "评估这段文案的政策契合度：[文案内容]"

## 使用示例

### Claude Desktop 对话示例

```
用户：用双向导航审计这段文案："这是全网第一的赚钱秘籍，绝对不封号，私信我领链接！"

甄先生：
🔴 红灯 · 风险点
  [HIGH] 第一 → 绝对化用语，违反《广告法》第九条
  [HIGH] 绝对 → 绝对化断言，缺乏实证支撑
  [MEDIUM] 私信 → 诱导私域导流
  [MEDIUM] 领取 → 利益诱导
  [MEDIUM] 赚钱 → 金钱承诺

🟢 绿灯 · 激励点
  💡 未检测到明显激励特征，建议增加实证/原创元素

📊 政策契合度
  综合评分: 25/100 (D · 高风险)

💡 优化建议
  1. 🔴 紧急：替换高风险词「第一」「绝对」
  2. 🟡 注意：修改营销诱导词「私信」「领取」「赚钱」
  3. 📊 政策契合度提升：重点优化「原创度」「真实性」「价值性」维度
```

## 重启说明

修改配置后重启 Claude Desktop，在对话中即可直接调用上述工具。
