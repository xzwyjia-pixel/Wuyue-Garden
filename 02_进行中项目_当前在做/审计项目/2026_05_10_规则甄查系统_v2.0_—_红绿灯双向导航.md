# 规则甄查系统 v2.0 — 红绿灯双向导航

短视频规则审计脚手架。新媒体合规审计工具集。

## 核心功能

- **红灯避险**: 负向拦截违规风险（封号/限流）
- **绿灯起量**: 正向挖掘政策激励点（流量加权/平台扶持）
- **政策契合度**: 原创度/真实性/价值性/合规性评估

## 模块

| 目录 | 用途 |
|------|------|
| `core/` | 审计引擎 + MCP 服务 |
| `agents/` | 编排器、调度器、模拟器 |
| `rules_engine/` | 规则进化、清理、批量审计 |
| `content_pipeline/` | 合规改写、内容导出、政策脚本 |
| `monitoring/` | 平台哨兵、趋势采集、雷达扫描、视觉守卫 |
| `feedback/` | 用户反馈采集与分析 |
| `analysis/` | 深度洞察、矩阵蒸馏/发布、同步 |
| `scripts/` | 启动脚本、部署工具 |
| `data/` | 运行数据、导出文件 |
| `docs/` | 文档、测试报告 |
| `notes/` | 调研笔记 |
| `tests/` | 测试用例 |

## 运行

```bash
cd 01-Production/规则甄查系统
python core/audit_core.py "待审计文案"
python -m pytest tests/ -v
```
