## 石化盈科

一、 系统现状与优化建议
现状方案：
您目前已在本地环境打通了具备“谐音穿透”能力的规则检测引擎，这保证了内容输出的安全基调。
优化建议：

从“工具运行”向“业务流”转型：目前的 audit_tool.py 仅是孤立的 Skill，需要将其封装进一个专门负责“石化行业内容创作”的 Agent 工作流中。
建立私有知识库：利用您的工业自动化背景（Siemens/ABB 经验），在 RulesBureau 文件夹下建立一个关于石化盈科数字化转型方案的 Knowledge 目录，供 Agent 检索。


二、 为“石化盈科”定制的 Agent 与 Skill 建立方案
您可以利用现有的开源模型（如 Qwen 2.5 或 Llama 3）在本地免费建立以下模块：
1. “行业洞查”Agent (Skill: 关联性分析)

Skill 逻辑：

输入：北京伟联私有云产品的技术参数。
分析：对比石化盈科在 ERP、MES 或智能工厂领域的公开技术需求。
产出：挖掘出“伟联边缘计算网关如何解决石化生产线异构协议接入”等跨界商机点。


建立方法：新建一个 industry_insight.py 脚本，利用 LLM 分析产品说明书与行业痛点的匹配度。

2. “甄先生”短视频创意 Agent (Skill: 避坑脚本生成)

Skill 逻辑：

特色：利用“避坑”人性，针对石化行业数字化转型的常见错误（如：数据孤岛、网络安全隐患）生成脚本。


建立方法：建立一个 script_engine.py，配置 System Prompt 为：“你是一位拥有 45 年经验的项目管理专家，请用‘避坑’视角为石化盈科的工程师写一段 30 秒脚本，推介伟联私有云的安全性。”。

3. “合规发布”Agent (Skill: 穿透式审核)

Skill 逻辑：

作用：使用您已跑通的 audit_tool.py 逻辑。
