全景知识库\n\n> 销售代理：甄先生\n> 背景：8年 Siemens / ABB 工业自动化经验\n> 状态：**在营** — 通过系统集成商（SI）渠道销售\n\n---\n\n## 一、公司概况\n\n| 项目 | 内容 |\n|------|------|\n| 公司 | 北京伟联（VLink） |\n| 产品 | 工业级私有云（超融合一体机） |\n| 定位 | 工业数据底座 + 计算+存储+网络三合一\n- **边缘计算盒子** — 轻量化工业级，适应恶劣环境\n- **零信任安全网关** — 替代传统 VPN，无需公网 IP\n- **工业协议转换网关** — OT/IT 打通（Modbus, SL651, OPC UA 等）\n\n### 2.2 技术特性\n- CPU：海光 Hygon 5440（国产 x86 架构，24核+）\n- 超融合：两节点 HA 高可用冗余\n- 操作系统：适配银河麒麟、统信 UOS（信创）\n- 虚拟化：国产虚拟化软件，永久授权\n- 数据加密：物理随机数硬件加密 + 加密卡（可选）\n- 工控协议：Modbus TCP/IP, EtherNet/IP, SL651（水利规约）\n- 容器化：支持 Docker / K8s 云原生部署\n\n### 2.3 核心竞争力\n1. **极简运维** — 远程调试，免现场维护，自动恢复\n2. **零信任安全** — 内网穿透，不改变现有网络结构\n3. **信创适配** — 龙芯/飞腾 + 麒麟/统信全面兼容\n4. **工业基因** — 老旧 PLC 接入、异构协议转换\n5. **\"不碰业务逻辑\"** — 只做底层底座，不抢上层应用\n\n---\n\n## 三、服务器与硬件架构分析\n\n### 3.1 超融合一体机架构\n```\n+-----------------------------------------+\n|           超融合一体机（两节点）            |\n|  +-----------+     +-----------+         |\n|  |  节点 A   |     |  节点 B   |         |\n|  | Hygon 四、服务器分析（控制网 vs 业务网）\n\n### 控制网超融合一体机\n- 物理隔离或强逻辑隔离\n- 工业协议识别（Modbus, PLC 监视）、CP5611 等通讯卡虚拟化\n- 实时库（Real-time DB）+ 时序数据库（TSDB）\n- **风险**：需确认存储网络与管理网络是否物理隔离\n\n### 业务网超融合一体机\n- 支持国产 OS + 国产数据库适配\n- 视频摄像头采集显示（⚠️确认 GPU 是否配置）\n- 数字孪生 3D 模型渲染 / 办公管理平台承载\n\n---\n\n## 五、集成商生态全景\n\n### 5.1 行业龙头（全国性覆盖）\n- **中国电建**（中南院、华东院）— 数字孪生、智慧枢纽最大集成商\n- **长江委下属** — 长江流域大坝监测、水资源调度\n- **石化盈科** — 工业互联平台 +
