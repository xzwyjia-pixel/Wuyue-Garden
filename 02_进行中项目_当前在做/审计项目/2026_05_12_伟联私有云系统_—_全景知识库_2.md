## 二、产品体系

### 2.1 核心产品
- **工业私有云超融合一体机** — 计算+存储+网络三合一
- **边缘计算盒子** — 轻量化工业级，适应恶劣环境
- **零信任安全网关** — 替代传统 VPN，无需公网 IP
- **工业协议转换网关** — OT/IT 打通（Modbus, SL651, OPC UA 等）

### 2.2 技术特性
- CPU：海光 Hygon 5440（国产 x86 架构，24核+）
- 超融合：两节点 HA 高可用冗余
- 操作系统：适配银河麒麟、统信 UOS（信创）
- 虚拟化：国产虚拟化软件，永久授权
- 数据加密：物理随机数硬件加密 + 加密卡（可选）
- 工控协议：Modbus TCP/IP, EtherNet/IP, SL651（水利规约）
- 容器化：支持 Docker / K8s 云原生部署

### 2.3 核心竞争力
1. **极简运维** — 远程调试，免现场维护，自动恢复
2. **零信任安全** — 内网穿透，不改变现有网络结构
3. **信创适配** — 龙芯/飞腾 + 麒麟/统信全面兼容
4. **工业基因** — 老旧 PLC 接入、异构协议转换
5. **"不碰业务逻辑"** — 只做底层底座，不抢上层应用

## 三、服务器与硬件架构分析

### 3.1 超融合一体机架构
```
+-----------------------------------------+
|           超融合一体机（两节点）            |
|  +-----------+     +-----------+         |
|  |  节点 A   |     |  节点 B   |         |
|  | Hygon     |     | Hygon     |         |
|  | 5440 x2   |     | 5440 x2   |         |
|  | 256GB     |     | 256GB     |         |
|  | SSD x4    |     | SSD x4    |         |
|  | HDD x4    |     | HDD x4    |         |
|  +-----+-----+     +-----+-----+         |
|        +-------+-------+                  |
|                v                          |
|         虚拟化资源池                        |
|    (国产虚拟化 + 容器)                     |
+-----------------------------------------+
```

### 3.2 硬件基线配置
- 处理器：国产 Hygon 5440（建议招标改参数描述防排他）
- 内存：≥256GB，支持 DDR4 ECC
- 存储：SSD 缓存层 + HDD 容量层，≥4 盘位
- 网络：万兆光纤 + 千兆管理口
- 扩展：支持 GPU 卡（视频 AI 分析场景）
- 加密：可选物理加密卡（约 1 万元/块）

### 3.3 竞品控标满足度
| 厂商 | 处理器 | 资质满足 | 工控协议 | 评价 |
|------|--------|---------|---------|------|
| **中科曙光** | 海光（亲儿子） | ✅全套 | ⚠️需插件 | 硬件最匹配 |
| **新华三 H3C** | 海光产线 | ✅齐全 | ⚠️需插件 | 水利案例多 |
| **深信服** | 海光底座 | ✅齐全 | ✅深度 | 安全参数最契合 |
| **华为** | 鲲鹏 ARM | ❌无海光 | -- | 无法应标 |
| **奇安信/天融信** | 海光底座 | ✅齐全 | ✅溢出 | 硬件性能偏弱 |

## 四、服务器分析（控制网 vs 业务网）

### 控制网超融合一体机
- 物理隔离或强逻辑隔离
- 工业协议识别（Modbus, PLC 监视）、CP5611 等通讯卡虚拟化
- 实时库（Real-time DB）+ 时序数据库（TSDB）
- **风险**：需确认存储网络与管理网络是否物理隔离

### 业务网超融合一体机
- 支持国产 OS + 国产数据库适配
- 视频摄像头采集显示（⚠️确认 GPU 是否配置）
- 数字孪生 3D 模型渲染 / 办公管理平台承载

## 六、项目进展

### 6.1 核心项目：洪泥河

- **文件**：初步设计报告 + 伟联修改内容
- **策略**：超融合一体机替代物理服务器

- **资质门槛**：中国信息安全测评中心三级 + ITSS 二级
- **风险**：排他性过强 → 建议改为参数描述防废标

### 6.2 当前推进策略
- 跳过设计院，直接对接系统集成商
- 定位："工业数据底座"，非硬件销售
- 核心话术："信创环境下的工业数据底座"
- 目标人群：技术总监（CTO）/ 水利事业部总经理
- 样板间：石化盈科案例背书

### 6.3 合作模式
- **被集成** — 伟联作为 SI 方案的 IT 基础设施模块
- **补短板** — SI 负责业务，伟联负责数据底座
- **降成本** — 帮助 SI 省去云架构师团队
- **零信任安全** — 帮助 SI 通过等保评审

## 七、控标策略

### 7.1 核心控标点
1. **信创导向**：海光 CPU + 国产虚拟化 + 国产 OS/数据库
2. **高集成度**：超融合一体机 = 硬件 + 虚拟化管理平台绑定
3. **严苛资质**：信息安全三级 + ITSS 二级 = 排他门槛
4. **工业协议**：Modbus/PLC 支持 = 缩小范围（深信服、奇安信）

### 7.2 合规风险
- ⚠️ 直接写 Hygon 5440 型号 = 指定品牌，违反《招标投标法实施条例》
- ⚠️ 资质组合需确认市场≥3 家满足（防止废标）
- ⚠️ "镜像"表述不专业 → 建议改为"多副本"或"RAID"
- ⚠️ 视频采集需确认是否配 GPU

### 7.3 说服 SI 的三个加分项
1. **"不碰业务逻辑"** — 消除 SI 怕被抢客户的顾虑
2. **信创适配** — 政府/能源/水利投标刚需
3. **极简运维** — 节省 SI 的现场工程师成本
