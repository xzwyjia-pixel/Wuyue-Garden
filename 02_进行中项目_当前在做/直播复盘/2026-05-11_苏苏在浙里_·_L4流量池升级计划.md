## P0. 开播前(30分钟) — 准备决定结果

### 0.1 每场直播前必发1条预热短视频

**为什么:** 预热视频给直播引流+激活粉丝→开播时初始在线人数从0→5+
**算法逻辑:** 开播前1h发短视频→用户看到视频头像闪烁→点击进入直播间

**操作流程(15分钟做完):**

```
Step 1 (3min)  手机横拍15s:
                 — 今天要做的菜(食材摆桌上)
                 — 苏苏对着镜头说一句话:
                   "今天做丝瓜汤和泡椒牛肉, 想学的点个预约"
                 — 注意: 不要拍灶台, 拍人脸+食材

Step 2 (2min)  剪映剪辑:
                 — 直接发, 不加特效
                 — 字幕挂"今晚X点直播, 教做丝瓜汤"

Step 3 (1min)  发布:
                 — 标题带: "苏苏在浙里" + "家常菜"
                 — 位置: 浙江(开启同城流量)

Step 4 (9min)  回复评论:
                 — 有人评论就回, 哪怕只回"嗯嗯"
                 — 算法判定: 此账号活跃→开播时给初始推流
```

**发布时机:** 直播前1-2小时
**成本:** 15分钟/次, 零钱

## P2. 下播后(30分钟) — 把一场直播变成3条流量

### 2.1 直播切片(每场剪3条, 每条15-30s)

**切片选择标准:**

| 切片类型 | 选哪个片段 | 时长 | 标题示例 | 什么时候发 |
|---------|-----------|------|---------|-----------|
| 高光展示 | 食物饱和度最高的时刻 | 15-20s | "丝瓜汤这样做, 鲜掉眉毛" | 直播结束后立即 |
| 互动 Moment | 姐品鉴/三人互动 | 20-30s | "姐尝了一口, 表情说明一切" | 第二天上午 |
| 教学干货 | 苏苏讲干货片段 | 20-30s | "炒牛肉不老的秘密" | 第二天晚上 |

**算法逻辑:**
- 直播切片自带"直播引流"标签 → 推流权重比普通视频高30%
- 切片挂"看完整直播"链接 → 引导去直播间 → 直播权重提升
- 3条切片 = 3次曝光机会 × 平均500-2000曝光 = 1500-6000额外曝光

**剪映操作(15分钟/条):**
```
1. 找到对应时间点(用分析报告的food_sat峰值定位)
2. 裁剪15-30s
3. 加字幕(自动识别, 改错别字)
4. 加标题封面: "苏苏教你XX菜"
5. 发布时挂"直播回放"链接
```

## P3. 基础建设(第一周内完成)

### 3.1 灯光(¥100, 30分钟)

按执行手册1.1的坐标:
- 补光灯B放左前方1.2m(解决左暗区)
- 现有灯加橙色色纸(提升暖色比)
- 验收标准: 左墙≈右墙亮度, 差值<20

### 3.2 锅具垫高(¥0, 2分钟)

- 灶台垫不锈钢架或厚砧板
- 验收: 海燕从手机看, 能看到苏苏眼睛

### 3.3 直播频次固定(每周3次)

```
当前: 低频不定时 → 账号权重衰减中
改:   每周二四六 早上7:00-8:30

为什么固定频次重要:
  算法记录"活跃账号"周期为7天
  每周3次 = 7天内有3次活跃信号
  连续2周 = 账号标签固化(美食/生活)
  连续1月 = 权重额外+5%(坚持奖励)

如果做不到3次, 至少:
  周二直播 + 周四发条视频 + 周六直播
  保持7天内至少有2次活跃动作
```
