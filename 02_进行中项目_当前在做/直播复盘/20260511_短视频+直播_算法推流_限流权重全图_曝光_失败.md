## 一、流量池等级体系（推流的"梯子"）

```
                        ┌─────────────────────────┐
                        │   L7: 热门推荐          │
                        │   1000万+ 曝光           │
                        │   进入"精选tab"          │
                        └─────────┬───────────────┘
                                  │ 通过: 实时互动率>15% + 转化>5%
                                  │ 失败: 退回L5-L6徘徊
                        ┌─────────┴───────────────┐
                        │   L6: 大流量池           │
                        │   100万-500万 曝光        │
                        │   同城热门 + 兴趣推荐      │
                        └─────────┬───────────────┘
                                  │ 通过: 停留时长>120s + 互动率>10%
                                  │ 失败: 退回L4-L5
                        ┌─────────┴───────────────┐
                        │   L5: 中级流量池          │
                        │   30万-100万 曝光         │
                        │   兴趣推荐为主             │
                        └─────────┬───────────────┘
                                  │ 通过: 完播率>45% + 点赞率>5%
                                  │ 失败: 退回L3-L4
                        ┌─────────┴───────────────┐
                        │   L4: 流量池测试期        │
                        │   5万-30万 曝光           │
                        │   标签匹配用户测试         │
                        └─────────┬───────────────┘
                                  │ 通过: 互动率>5% + 2次观看>20%
                                  │ 失败: 退回L2-L3 或 停止推流
                        ┌─────────┴───────────────┐
                        │   L3: 初始推荐池          │
                        │   5000-3万 曝光           │
                        │   粉丝 + 相似标签用户      │
                        └─────────┬───────────────┘
                                  │ 通过: 完播率>30% + 点赞>3%
                                  │ 失败: 停止推流(死亡)
                        ┌─────────┴───────────────┐
                        │   L2: 小范围测试          │
                        │   500-3000 曝光           │
                        │   粉丝为主                 │
                        └─────────┬───────────────┘
                                  │ 通过: 完播率>25% + 互动>0
                                  │ 失败: 停止推流
                        ┌─────────┴───────────────┐
                        │   L1: 初始流量            │
                        │   200-500 曝光            │
                        │   粉丝 + 随机分配          │
                        └─────────────────────────┘
```

**苏苏当前状态预估: L2-L3 徘徊**
- 新号+低频直播 → 初始权重低
- 零互动数据(无封闭式指令) → 完播率/互动率不达标 → 推不上去
- **核心矛盾**: 内容质量ok(菜做得好)但算法数据差(停留/互动/转化全挂)

## 二、短视频推流权重公式（数值化）

### 2.1 权重总分 = 六维加权

```
权重总分 = 完播率×30% + 互动率×25% + 转化率×20% + 停留时长×15% + 新鲜度×5% + 账号权重×5%
```

| 维度 | 权重 | 满分 | 苏苏当前(估) | 健康基准 | 影响 |
|------|------|------|-------------|---------|------|
| 完播率 | 30% | 100 | 25-35 | >45%才能进入L4 | 视频切片不够抓人 |
| 互动率 | 25% | 100 | **3-8** | >15%才能持续推 | **最大短板, 零封闭指令** |
| 转化率 | 20% | 100 | **<1** | >3%进入L5+ | 无商品链接=0转化 |
| 停留时长 | 15% | 100 | 40-60 | >90s进入L4 | 内容有吸引力但缺钩子 |
| 内容新鲜度 | 5% | 100 | 60 | >50即可 | 每道菜不同, 尚可 |
| 账号权重 | 5% | 100 | **15-25** | >50才有初始推流 | 新号+低频更新 |

> **苏苏当前加权总分 ≈ 25-35/100 → 卡在L2-L3**
> **目标: 60+ → 进入L4-L5**

### 2.2 各维度详细权重拆解

#### 完播率(30%) — 算法第一权重

```
短视频完播率:
  [0-15%]  ❌ 死亡区 — L1都不给, 停止推荐
  [15-25%] ⚠️ 及格线 — L2基础流量
  [25-45%] ✅ 健康区 — L3-L4
  [45-60%] 🔥 优秀区 — L5-L6
  [60%+]   💥 爆款区 — L7热门

直播停留(类似完播率):
  [<30s]    ❌ 死亡 — 算法判定封面欺诈
  [30-60s]  ⚠️ 及格 — 基础推流
  [60-120s] ✅ 健康 — L3-L4推流
  [120s+]   🔥 优秀 — 跨池推送
  [300s+]   💥 铁粉 — 标签固化
```

#### 互动率(25%) — 苏苏最大杠杆

```
互动率 = (评论+点赞+分享+收藏) / 曝光人数

┌─────────────┬──────────┬──────────┬──────────┐
│ 互动类型     │ 权重系数  │ 抖音     │ 视频号   │
├─────────────┼──────────┼──────────┼──────────┤
│ 评论         │ ×1.5     │ ─── 最高价值互动 ── │
│ 分享         │ ×2.0     │ ─── 算法"裂变信号" ── │
│ 点赞         │ ×0.5     │ 最轻量, 权重最低    │
│ 收藏         │ ×1.2     │ 用户"价值认可"信号  │
│ 关注         │ ×3.0     │ ─── 最高权重 ──    │
│ 扣1/扣2      │ ×1.0     │ 轻量评论, 但胜在量大 │
│ 点击购物车   │ ×2.5     │ 商业信号, 权重极高  │
└─────────────┴──────────┴──────────┴──────────┘

阈值标准:
  [<1%]    ❌ 死亡 — 账号标签模糊, 停止推流
  [1-3%]   ⚠️ 低互动 — 勉强维持L2
  [3-5%]   ✅ 正常 — L3基础推流
  [5-10%]  🔥 高互动 — L4-L5加速推
  [10%+]   💥 爆款 — 人工审核+热门推荐
```

#### 转化率(20%) — 商业价值核心

```
直播转化率 = 下单人数 / 观看人数

  [<0.5%]   ❌ 无商业价值 — 平台不倾斜资源
  [0.5-1%]  ⚠️ 低转化 — 勉强及格
  [1-3%]    ✅ 正常 — 带货直播间基准线
  [3-5%]    🔥 高转化 — 平台给额外流量扶持
  [5%+]     💥 头部 — 定向大推流

注意: 苏苏当前转化=0(无商品链接)
      即使不上商品, "关注转化率"同样被计算
      关注转化率基准: >3% 算健康
```

## 三、限流机制全图（权重的"刹车"）

### 3.1 限流等级金字塔

```
                        ┌──────────────────────────┐
                        │  L5: 永久封禁             │
                        │  账号注销, 身份证拉黑      │
                        │  触发: 严重违规×3         │
                        └─────────┬────────────────┘
                                  │
                        ┌─────────┴────────────────┐
                        │  L4: 长期限流(7-30天)     │
                        │  仅粉丝可见, 不推荐       │
                        │  触发: 营销过度/搬运/虚假  │
                        └─────────┬────────────────┘
                                  │
                        ┌─────────┴────────────────┐
                        │  L3: 中期限流(3-7天)      │
                        │  降权, 仅推荐给已关注      │
                        │  触发: 内容违规/诱导/夸大  │
                        └─────────┬────────────────┘
                                  │
                        ┌─────────┴────────────────┐
                        │  L2: 短期限流(24-72h)     │
                        │  减少推荐, 仅同城可见      │
                        │  触发: 低质内容/过度引流   │
                        └─────────┬────────────────┘
                                  │
                        ┌─────────┴────────────────┐
                        │  L1: 轻量限流(单条)       │
                        │  仅粉丝可见, 不进入推荐池  │
                        │  触发: 搬运/重复/水印     │
                        └──────────────────────────┘
```

### 3.2 限流触发条件权重表（按严重程度）

| 类别 | 触发条件 | 限流等级 | 恢复方式 | 苏苏风险 |
|------|---------|---------|---------|---------|
| **内容违规** | 涉政/涉黄/暴力 | L5永久 | 不可恢复 | 低 |
| **营销过度** | 口播频率>30%含促销词 | L3-L4 | 7天正常发 | 中(要注意) |
| **诱导互动** | "转发抽奖/不转不是中国人" | L3 | 删除 | 中(话术设计要注意) |
| **搬运/盗用** | 非原创内容>50% | L4 | 申诉 | 低 |
| **虚假宣传** | "吃了能治病/三天瘦十斤" | L4 | 扣分+限流 | 低(美食不涉及) |
| **低质内容** | 画面模糊/声音不清/无主题 | L2 | 提升质量 | **高(当前亮度/饱和度低)** |
| **内容重复** | 相似内容>60% | L2 | 创新 | 中(每天做菜容易重复) |
| **完播率低** | 连续3条<15% | L1-L2 | 优化前3秒 | **高(零互动导致完播差)** |
| **互动率低** | 连续5条<1% | L1 | 加互动钩子 | **严重(当前3-8%)** |
| **刷量/作弊** | 异常数据波动 | L5 | 不可恢复 | 低 |
| **引流出平台** | 微信/电话/二维码 | L3-L4 | 7天冷静 | 中(视频号引流注意分寸) |
| **未成年人问题** | 未成年人打赏/出镜 | L3 | 整改 | 中(姐的年龄不能明确提及) |

### 3.3 权重分衰减机制（"不更新就掉权"）

```
┌─────────────────────────────────────────────────┐
│               账号权重时间衰减曲线                  │
│                                                   │
│  权重                                               │
│  100 ┤ ████████                                    │
│   90 ┤ ████████ ██                                 │
│   80 ┤ ████████ ████                              │
│   70 ┤ ████████ ██████  ← 7天不更新掉至此          │
│   60 ┤ ████████ █████████                          │
│   50 ┤ ████████ ████████████  ← 15天不更新         │
│   40 ┤ ████████ ████████████████                   │
│   30 ┤ ████████ ████████████████████  ← 30天       │
│   20 ┤ ████████ ██████████████████████████         │
│   10 ┤ ████████ ████████████████████████████████   │
│    0 └───────────────────┬───┬───┬───┬───┬───      │
│                         1   3   7  15  30  60  天    │
└─────────────────────────────────────────────────┘

关键衰减:
  3天不更新 → 权重降5%
  7天不更新 → 权重降15% (新账号更敏感)
  15天不更新 → 权重降30% (标签开始模糊)
  30天不更新 → 权重降50% (几乎重置)
  60天不更新 → 权重降80% (等同新号)

恢复规则:
  连续3天更新 → 恢复至衰减前80%
  连续7天更新 → 完全恢复
  连续15天更新 → 权重额外+5%(坚持奖励)
```

## 四、抖音 vs 视频号 算法差异

### 4.1 核心差异对比

| 维度 | 抖音 | 视频号 | 对苏苏的影响 |
|------|------|--------|------------|
| 推流逻辑 | 兴趣推荐(标签驱动) | 社交推荐(好友点赞驱动) | 视频号需要引导"转发朋友圈" |
| 完播率权重 | 30% | **40%**(更高) | 视频号前3秒更重要 |
| 互动权重 | 评论>分享>点赞 | **分享>评论>点赞** | 视频号多做"转发抽奖"类 |
| 粉丝粘性 | 低(算法喂流量) | 高(社交关系链) | 视频号适合人设型内容 |
| 商业化容忍 | 高(广告多) | **低**(限制更严) | 视频号不能太像带货 |
| 直播入口权重 | 高(直播tab) | 中(朋友圈/群聊) | 视频号直播依赖私域裂变 |
| 新号扶持 | 7天新手期 | **30天冷启动期** | 视频号新号更容易起量 |
| 限流严格度 | 中等 | **严格**(微信生态) | 视频号话术要更温和 |
| 本地推流 | 同城页(强) | 附近(弱) | 抖音适合"苏苏在浙里"同城引流 |

### 4.2 双平台差异化运营策略

```
抖音策略: 算法驱动, 追求数据指标
  ├─ 前3秒必须有冲击力(不要"大家好", 直接展示菜品)
  ├─ 每5分钟1次强互动钩子(扣1/扣2)
  ├─ 利用同城页: 标题带"浙江/泰州"等地理标签
  └─ 视频切片: 每场直播剪3条, 挂直播预告

视频号策略: 关系驱动, 追求信任感
  ├─ 开场先聊两句(视频号用户接受慢节奏)
  ├─ 每8分钟1次"帮转一下"引导(利用社交裂变)
  ├─ 私域配合: 直播前发朋友圈/群聊预告
  └─ 视频切片: 突出"人设"和"温馨感", 减少叫卖感
```

### 5.3 "扣1"的算法价值量化

```
1次"扣1"互动在算法中的实际价值:

用户扣1 → 评论+1(权重系数×1.5)
        → 互动率分母+1, 分子+1
        → 算法判定: 直播间活跃度高
        → 推送给更多相似标签用户
        → 新用户进来 → 看到很多评论 → 从众效应也留言

1次扣1指令 ≈ 5-15条实际评论
5条评论 ≈ 互动率提升0.1%
互动率5%→10% ≈ 流量池从L3→L5

量级换算:
  口播1次"扣1" = 15-25条评论互动
  15-25条评论 = 曝光量提升300-500人
  300-500人曝光 = 新增关注3-10人
  3-10人新增关注 = 长期权重+0.5%

一句话: 一句"扣1"的算法价值 = 500-1500次曝光
         全程11句 = 5500-16500次曝光增量

成本: 零成本, 只需要开口说
```

## 六、权重速查卡(直播中贴墙用)

| 行为 | 扣分 | 后果 |
|------|------|------|
| 画面昏暗 | -停留时长 | 推流减少 |

| 长时间无互动 | 算法判定"冷场" | 停止推流 |
