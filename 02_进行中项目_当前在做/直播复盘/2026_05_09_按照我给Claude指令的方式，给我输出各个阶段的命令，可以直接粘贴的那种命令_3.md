## 按照我给Claude指令的方式，给我输出各个阶段的命令，可以直接粘贴的那种命令

既然你已经跑通了整体逻辑，我们要做的就是把这些“想法”转化为可以直接喂给 Claude Code 或 AI Agent 的指令（Prompts）。这些命令按照你项目的生命周期进行了分类，确保“正向激励”与“负向甄查”双线并行。
你可以直接复制以下内容到你的对话框中：

第一阶段：自动化爬取与案例筛选逻辑
指令目标：配置爬虫或筛选逻辑，优先抓取 2026 年新规下的极端案例（封号/限流）和官方扶持方向。

复制以下指令：
“请基于 Python 编写一个数据筛选脚本，对接我爬取到的抖音/视频号评论区和视频描述数据。

负向抓取：优先识别包含‘封号’、‘限流’、‘不给推流’、‘违规提醒’关键词的内容，并将对应的博主资料和视频元数据整理到 /data/risk_cases 文件夹。
正向抓取：识别包含‘官方扶持’、‘激励计划’、‘2026新规方向’、‘鼓励原创’关键词的内容，整理到 /data/growth_opportunities 文件夹。
输出要求：生成一个 JSON 摘要，对比两组数据中提到的 2026 年平台政策变化核心点。”



第二阶段：升级 MCP 审计服务器 (zhen-audit)
指令目标：让你的 audit_core.py 逻辑具备“红绿灯”双向判断能力。

复制以下指令：
“请修改当前的 mcp_audit_server.py 及其核心逻辑 audit_core.py：

增加双向审计逻辑：在原有的违规词（红灯）检测基础上，增加一个‘政策契合度（绿灯）’检测模块。
逻辑参考：绿灯模块需参考 2026 年平台鼓励的‘高价值、长效互动、实证类’创作思路。
返回格式调整：工具调用返回结果必须包含：

[风险点]：哪些内容可能触发行前述爬取到的案例坑点。
[激励点]：哪些内容符合平台当前的流量扶持政策。
[优化建议]：如何将违规内容转化为平台鼓励的内容。”





第三阶段：短视频脚本生成（规则解读+案例分享）
指令目标：利用爬取到的详细案例，生成具有“甄查”风格的内容脚本。

复制以下指令：
“请作为‘规则甄查’自媒体的主理人，为我创作一段短视频脚本。

参考素材：使用 /data/risk_cases 中最近下载的一个被限流博主案例作为开场钩子。
核心内容：拆解 2026 年抖音/视频号针对该类行为的最新的具体政策变化。
正向引导：结合平台鼓励的‘绿灯’思路，给出三个具体的修改建议，告诉观众如何做才能获得官方推流。
视觉风格：保持‘简约精准、工业级、静奢风’的调性描述。”



第四阶段：项目进度同步与存档
指令目标：确保 Claude 记忆住今天的修正逻辑，防止后续跑偏。

复制以下指令：
“请更新当前项目的 Readme 文档或 Context 记录：

核心品牌：‘规则甄查 - 甄先生’。
执行准则：坚持‘红灯避险+绿灯导航’双线审计逻辑。
当前进度：已完成 MCP JSON-RPC 2.0 重构，正处于 2026 新规数据集成阶段。
特别提醒：所有审计结果必须引用真实爬取到的封号/限流案例作为支撑。”
