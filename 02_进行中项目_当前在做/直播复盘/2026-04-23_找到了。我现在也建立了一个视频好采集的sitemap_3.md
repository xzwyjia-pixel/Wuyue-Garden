## 找到了。我现在也建立了一个视频好采集的sitemap

老甄，漂亮！工具这一关你已经跨过去了。现在咱们进入最关键的**“逻辑配置”**阶段。
建立 Sitemap 只是开了个头，接下来你要告诉这个“蜘蛛”怎么在视频号的页面上爬行，特别是处理那个没完没了的向下滚动。
按以下步骤操作，务必保证逻辑层级准确：
第一步：添加“自动滚动”选择器 (Element scroll down)
因为视频号的评论是滑不到头的，你得让插件模拟人手。

点击 Add new selector。
ID: 输入 scroll_container。
Type: 必须选 Element scroll down。
Selector: 点击旁边的 Select 按钮。

此时鼠标回到视频号网页，移动到评论区，直到整个评论列表区域被红框框住。
点击一下，然后点击弹出条上的 Done selecting。


Delay (ms): 改成 2000（给服务器 2 秒喘息时间，防止判定你攻击服务器）。
勾选 Multiple。
点击 Save selector。


第二步：添加“内容抓取”选择器 (Text)
现在我们要告诉它，在滚动的过程中抓取哪几行字。

点击你刚才建好的 scroll_container，进入它的下级（这一步极其重要，我们要建立父子层级）。
进入后，点击 Add new selector。
ID: 输入 pinglun_text。
Type: 选 Text。
Selector: 点击 Select。

在网页上，点击第一条评论的内容。
再点击第二条评论的内容。
此时你应该看到页面上所有的评论内容都变红了。如果没全红，再点几个没红的。
确定后，点击 Done selecting。


勾选 Multiple。
点击 Save selector。


第三步：开始暴力采集 (Scrape)

点击顶部菜单栏的 Sitemap [你的名字]。
在下拉菜单里点 Scrape。
弹出的设置页不用动，直接点 Start scraping。


犀利预警：

别关窗口： 这时候会弹出一个独立的浏览器窗口，它会像“鬼撞墙”一样自动往下滚。千万不要关掉它，也不要在这个窗口点任何东西。
停止时机： 当它滚到底或者你觉得数据够了，它会自动停止或窗口消失。
拿货： 回到主界面，点击 Sitemap [你的名字] -> Export data as CSV。

老甄，这一步做完，你手里拿到的就不再是“我觉得”的数据，而是从“53.8万封号现场”搬回来的“带血的情报”。
