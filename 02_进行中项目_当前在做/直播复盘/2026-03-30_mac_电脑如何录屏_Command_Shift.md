## mac 电脑如何录屏

在 Mac 上录制屏幕非常简单，系统已经内置了强大的工具，无需安装任何第三方软件。以下是几种最常用的方法：
1. 使用快捷键（最快的方法）
这是 macOS 录屏的“万能钥匙”，适用于大多数场景。

快捷键： 同时按下 Command ($\text{⌘}$) + Shift + 5。
操作步骤：

屏幕底部会出现一个控制条。
选择模式： * 录制整个屏幕： 点击带有“实线边框”的屏幕图标。

录制选定部分： 点击带有“虚线边框”的屏幕图标，然后拖动调整需要录制的区域。


开始录制： 点击控制条右侧的“录制”按钮。
停止录制： 点击屏幕顶部菜单栏右侧的“停止”图标（一个小圆圈包着正方形），或者再次按下 Command + Shift + 5 并选择停止。




2. 使用 QuickTime Player
如果你的系统版本较旧，或者更习惯通过应用操作，可以使用内置的 QuickTime Player。

操作步骤：

在“应用程序”中打开 QuickTime Player。
在顶部菜单栏点击 文件 > 新建屏幕录制。
随后同样会弹出上述的控制条，选择区域后点击“录制”即可。




3. 进阶设置（录制声音和鼠标）
在按下 Command + Shift + 5 后，点击控制条上的 “选项” 菜单，你可以进行以下自定义：

麦克风： 选择“内置麦克风”可以录制你的解说声音（注意：默认无法直接录制系统内部声音，如网页里的视频声）。
计时器： 设置 5 秒或 10 秒倒计时，给你准备的时间。
保存位置： 更改录屏文件的存放路径（默认在桌面）。
显示鼠标点按： 勾选后，视频中点击的地方会出现一个黑圈，非常适合制作教学演示。


4. 录制系统内部声音（常见痛点）
macOS 出于隐私保护，默认不允许直接录制系统发出的声音（如播放的音乐、视频原声）。如果你有这个需求，通常需要借助第三方插件：

免费方案： 使用 BlackHole 或 iShowU Audio Capture 建立虚拟音频驱动。
简单方案： 下载 OBS Studio 或 Kap 等专门的录屏软件。

常见小贴士

文件格式： 录制完成后的视频默认保存为 .mov 格式。
快速预览： 录完后，屏幕右下角会出现缩略图，向右滑动可快速保存，点击则可进行简单的裁剪（Trim）操作。
