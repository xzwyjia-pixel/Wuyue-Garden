1. Windows 自带录制（Win + Alt + R）隐藏光标
你提到的 Win + G（Xbox Game Bar）录制功能，原生并没有直接开关来隐藏光标。

曲线救国法： 如果必须用这个软件，可以在 Windows 设置中搜索 “鼠标设置” -> “其他鼠标选项” -> “指针”，把指针方案换成一个极其微小的点，或者找一个透明的 .cur 文件图标替换。
建议方案： 既然你追求效率，建议下载一个 OBS Studio 或 Captura。这些工具在录制面板上有一个直接勾选的框：“捕捉光标”，取消勾选即可。

3. 剪映里的“放大镜”效果（关键帧操作）
不需要粘贴新图片，直接在剪映里通过**“关键帧”**实现平滑放大：

打第一个点： 在你想开始放大的时间点，选中视频条，点击右上角预览窗格下方的“小菱形”图标（关键帧）。
打第二个点： 向后拖动时间轴 1 秒，将预览画面用手指捏合或鼠标拉大，并移动到你想突出的数据位置。
