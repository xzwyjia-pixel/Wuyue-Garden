# 大山里的小桃 — 直播间人设审计系统

> 目标：对直播间进行人设审计，量化视觉风格与观众互动质量，对标"清晨烟火小厨"基准。

---

## 核心文件

| 文件 | 功能 |
|------|------|
| `monitor_桃.py` | 主监控脚本 — OCR 评论区 + 全景截图 + 人设 Triage |
| `triage_log.jsonl` | 每 5min 视觉评分记录 |
| `live_data_tao.jsonl` | 评论区 OCR 结果逐行追加 |
| `temp_frames/` | 全景截图存储 |
| `Audit_Report_XiaoTao.md` | 自动生成的周报 |
| `generate_audit_report.py` | 报告生成脚本 |
| `test_coords.py` | 坐标验证工具 |


### 模糊匹配阈值

```
FUZZY_TARGETS = [
    ("小桃", {"桃", "挑", "眺", "逃", "跳"}),  # 核心字集 + difflib 相似度 > 0.7
    ("好吃", {"好", "吃"}),
]
```

匹配规则：任一核心字命中 → difflib.SequenceMatcher 计算相似度，ratio >= 0.7 或含字即软命中。

### 单字模糊命中

```
FUZZY_CHARS = {"桃", "灶", "火", "姐", "香"}
```

## 人设 Triage 评分公式

### 真实感评分 (`score_authentic`)

| 条件 | 加分 |
|------|------|
| 亮度 > 60 | +10 |
| 对比度 > 35 | +15 |
| 暖色占比 > 0.15 | +15 |
| 绿色占比 < 0.40 | +10 |
| 纹理细节 > 30 | +15 |
| 色彩熵 > 4.5 | +10 |
| 食物区饱和度 > 50 | +15 |

### 道具感评分 (`score_staged`)

| 条件 | 加分 |
|------|------|
| 对比度 <= 35 | +10 |
| 暖色占比 <= 0.15 | +10 |
| 绿色占比 > 0.40 | +15 |
| 纹理细节 <= 30 | +10 |
| 色彩熵 <= 4.5 | +10 |

### 偏差值

```
diff = score_authentic - score_staged
```

- diff >= +20: 倾向真实厨房场景
- diff >= -10: 半真半道具
- diff < -10: 道具感偏重

## 视觉热区（"一桌菜"检测）

```
crop_top    = h * 0.66        # 画面下方 1/3
crop_bottom = h
crop_left   = w * 0.20        # 中心 60% 宽度
crop_right  = w * 0.80
```

检测指标：

| 指标 | 检测方式 | 触发条件 |
|------|---------|---------|
| 红色饱和度 | HSV H:0-10/170-180, S>100 | red_sat_ratio > 0.05 |
| 绿色饱和度 | HSV H:35-85, S>100 | green_sat_ratio > 0.08 |
| 诱导力评价 | 上述任一满足 + 食物区 sat_mean > 50 | "食欲诱导力强，具备高转化潜质" |

---

## 截图有效性判定

- 平均亮度 > 240: 判定为"无效截图"，跳过 Triage 报告更新
- OCR 返回 >5 段文字但命中为 0: 自动执行 `find_and_pin()` 重校准

---

## 对标维度（vs 清晨烟火小厨）

| 维度 | 计算方式 | 含义 |
|------|---------|------|
| 亮度 | gray.mean() | 画面明暗 |
| 对比度 | gray.std() | 细节锐度 |
| 暖色占比 | HSV H:0-25 像素占比 | 灶台火光/油烟氛围 |
| 纹理细节 | Laplacian std | 材质真实感 |
| 色彩熵 | HSV H 通道直方图熵 | 颜色层次丰富度 |
| 视觉呼吸感 | 色彩熵 / 亮度 × 100 | 观感"通透度" |
| 光影精致度 | 对比度 × 暖色占比 / 100 | 灯光质感 |
