## 我要全程用电脑操作。我手机没装Gemini app

既然你决定全程在电脑端闭环操作，且手机没有安装 Gemini App，那我们就必须将电脑打造成一个**“自主运行的直播审计站”**。
这种方式虽然少了语音互动的即兴感，但优势在于数据沉淀极其精准。你可以通过 Claude Code 编写一套“自动化脚本链”，让 AI 直接读取你电脑屏幕上的画面和文字，然后每隔几分钟在终端（Terminal）给你出一份“战报”。
以下是为你定制的电脑端全流程操作方案：
1. 核心逻辑：AI 审计官的“三位一体”
在电脑上，我们将系统拆分为三个并行运行的模块：

采集器 (The Eyes)： 负责每隔 30-60 秒截取一次屏幕上的直播间图像。
处理器 (The Brain)： 将截图发送给 AI 接口（或本地 OCR），解析出评论内容和画面特征。
反馈员 (The Voice)： 在你的 Claude Code 窗口或一个浮窗中，直接打印出诊断建议。


2. 立即执行：发给 Claude Code 的代码构建指令
请在你的 Claude Code 终端中依次输入以下内容。这些指令将帮你直接生成可以在电脑上后台运行的 Python 监控套件。

指令：
请在 E:\MyCodeProjects 下执行以下任务：


创建主程序 live_observer.py： >     - 使用 pyautogui 获取屏幕截图。

逻辑：自动识别标题包含“微信”的窗口（直播网页版），并精准截取直播画面区域和评论区区域。
存储：将评论区文字追加到 live_data.jsonl，全景图存入 temp_frames/。



集成“冲突感”实时预警逻辑：

编写一个函数 check_conflict_intensity()：监控过去 3 分钟内“哈哈”、“互动、吵架、有趣”等关键词的出现频次。
如果频次下降，在终端打印：⚠️ [警告] 直播间气氛变淡，建议触发“海燕”人设冲突。



集成“视觉审计”评分逻辑：

编写一个函数 audit_visual_style()：分析截图的亮度、对比度以及绿色像素占比（背景植被）。
如果画面杂乱或光线发灰，在终端打印：🔴 [视觉优化] 画面色调偏冷，建议增加暖色补光，调整精致姐站位。



环境检查： 确保安装了 pygetwindow 来精确定位窗口位置。




3. 如何进行“类似直播间”的实战验证？
为了验证这套系统，请你现在电脑上打开一个类似 “顺子在杭州” 或者 “阿雅在丽江” 的视频号网页版直播间，然后按照以下步骤操作：
A. 启动“实时监视器”
在 PowerShell 中运行：
python live_observer.py
此时，你会看到控制台不断跳出类似：[20:35] OCR识别成功，抓取到 12 条新评论... 的信息。
B. 触发“AI 深度复盘”
当你觉得这一段播得不错，或者想让 AI 帮你总结时，直接在 Claude Code 里输入：

“Claude，读取过去 15 分钟的 live_data.jsonl。参考‘清晨烟火小厨’的逻辑，告诉我刚才这段时间，主播的‘人设钩子’有没有勾住观众？为什么停留时长（推测值）在第 10 分钟掉了？”


4. 针对电脑端操作的改进建议（找出漏洞）
在测试中，你需要重点揪出以下三个电脑端常出的 Bug，并让 Claude 改进：

窗口遮挡问题： - 现象： 如果你开着监控去干别的（比如回微信），截图就会截到微信窗口。

改进： 让 Claude 增加 pygetwindow 强制置顶直播窗口，或者只截取特定后台进程的画面（这需要更复杂的底层调用）。


评论滚动太快：

现象： 热门直播间评论刷得飞起，30 秒截一次图会漏掉 90% 的话。
改进： 将 chat_interval 缩短到 5-10 秒，并加入 “文本模糊去重算法”，确保数据完整且不重复。


人设识别误差：

现象： AI 可能会把背景里的路人当成“精致姐”。
改进： 告诉 Claude 设定**“画面热区”**。例如：灶台左侧 30% 区域出现的人物默认为“实诚人”，后方背景区域出现的人物为“精致姐”。
