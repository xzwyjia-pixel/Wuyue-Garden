# 苏苏直播互动话术手册

**人设**: 江南农村宝妈厨师 | **场景**: 户外檐下厨房 | **风格**: 朴实温暖，像邻居大姐边做菜边聊天
**平台**: 视频号 | **核心菜式**: 丝瓜汤、泡椒牛肉、家常江南菜
**底线**: 所有话术避免诱导性词汇（转发/红包/必须），用自然引导替代

---

## 核心记忆法：钩 → 信 → 互 → 转 → 化

> **口诀**: 钩子留人，信服留客，互动留量，转化留钱，化解留面
> **本质**: 苏苏不是叫卖，是"边做菜边聊天"。让观众觉得"这大姐实在"比"这主播会喊"重要一百倍。

---

### 一、钩——留人（前15秒）

**口诀**: 开口就抛钩，别喊欢迎

| 类型 | 一句话话术 |
|------|-----------|
| 悬念钩 | "丝瓜发黑发苦？差这一步，农村土办法教你。" |
| 痛点钩 | "外面吃饭总拉肚子？15分钟做干净泡椒牛肉。" |
| 视觉钩 | （下锅滋啦声）"听这声音，对味不？" |
| 身份钩 | "冰箱总有剩菜不知道咋搭？苏苏教你一招。" |

---

### 二、信——信任建立（15秒-2分钟）

**口诀**: 亮手艺，讲故事，引共鸣

| 方法 | 一句话话术 |
|------|-----------|
| 秀专业 | "丝瓜要中小火慢慢焙出水才嫩，不信你试试。" |
| 讲故事 | "泡椒我去年秋天泡的，农村土方子。" |
| 引共鸣 | "以前城里天天外卖，回农村自己种自己烧，人轻快了。" |
| 低门槛 | "猜我锅里炖的啥？猜对念你名字。" |

---

### 三、互——互动推流（高价值，每3-5分钟一次）

**口诀**: 二选一，扣数字，别让观众想

| 方式 | 一句话话术 |
|------|-----------|
| 选择题 ★ | "炒牛肉嫩肉淀粉还是蛋清？扣1扣2。" |
| 共鸣题 | "从小吃妈妈做这道菜长大的，扣个'是'。" |
| 福袋题 | "公屏扣'苏苏菜谱'抽辣椒酱。" |
| 请教题 | "这锅汤颜色够白不？够的打'够'。" |

> **沉默观众激活法**: "不爱打字没事，双击屏幕就是点赞。觉得有用的评论区打1，1秒钟的事。"

---

### 四、转——关注/转化

**口诀**: 给理由再让点，别干喊'点点关注'

| 场景 | 一句话话术 |
|------|-----------|
| 加关注 | "怕做菜翻车，关注苏苏，每天一道家常菜不迷路。" |
| 加粉丝团 | "加粉丝团的姐妹，以后开播优先点名互动。" |
| 促购买 | "土锅用了七八年，链接挂下面了，一号链接。" |
| 老粉维护 | "欢迎XX姐，上次红烧肉成功了吗？" |

---

### 五、化——化解场面

**口诀**: 同行走欢迎，挑刺不硬刚

| 场景 | 一句话话术 |
|------|-----------|
| 同行来 | "同行朋友欢迎，苏苏做家常土菜，一起交流。" |
| 有人挑刺 | "各地方做法不一样，苏苏教的是江南农村家常做派。" |
| 说错了 | "做菜没标准答案，家里老人咋教就咋做。" |

---

## 实战节奏速查（一分钟看全场）

| 时间 | 干啥 | 口诀 |
|------|------|------|
| 开播前 | 社群发链接 | "马上开播，今天做泡椒牛肉" |
| 0-30秒 | 抛钩子 | "丝瓜发黑？差这一步" |
| 30秒-2分 | 亮手艺 | "泡椒我自己泡的" |
| 2-3分 | 第一轮互动 | "放不放蒜？扣1扣2" |
| 5-6分 | 挂福袋 | "扣'苏苏菜谱'抽酱料" |
| 8-10分 | 点名老粉 | "XX姐上次成功了吗" |
| 每3分 | 抛个问题 | 各种扣1扣2 |
| 15分 | 第二轮福袋 | 重复福袋引导 |
| 收尾 | 预告+关注 | "明早六点半教酸菜鱼" |
