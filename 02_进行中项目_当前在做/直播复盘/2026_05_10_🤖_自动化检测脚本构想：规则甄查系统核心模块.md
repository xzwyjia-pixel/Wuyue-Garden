# 🤖 自动化检测脚本构想：规则甄查系统核心模块

## 1. 流量池分配公平性探测 (Traffic Sandbox)
- **技术逻辑**：利用 Python + Playwright 模拟多组“纯净账号”（无历史标签），在相同条件下发布相同内容。
- **监控指标**：
    - 初始曝光时间（Time to First Impression）。
    - 流量来源占比（推荐 vs 搜索 vs 关注）。
- **目的**：检测是否存在算法层面的初始权重歧视。

## 2. 敏感词/违规词自动化穿透测试 (Content Auditor)
- **技术逻辑**：
    - 建立“变体词库”（如拼音、形近字、拆分字）。
    - 脚本自动生成带敏感内容的测试视频（利用现有 AI 视频生成接口）。
    - 自动化上传并监测“审核通过时间”及“存活时长”。
- **目的**：量化评估平台算法过滤系统的灵敏度与合规边界。

## 3. 算法开关生效性验证 (Privacy Opt-out Checker)
- **技术逻辑**：
    - 抓取关闭个性化推荐前后的 API 流量包。
    - 使用 NLP 模型对比关闭前后推荐内容的“相关度”与“重合度”。
- **目的**：验证平台是否真正履行了“关闭个性化推荐”的法律义务。

## 4. 自动化报告生成
- 集成 **Obsidian API**，将上述脚本的运行结果、截图及风险评估分值，自动汇总生成 Markdown 报告并推送到本项目库中。
