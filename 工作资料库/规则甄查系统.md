# 规则甄查系统

> AI 内容审计系统。基于规则的品牌合规检测 + MCP 服务。
>
> **路径**: `E:\MyCodeProjects\03-规则甄查系统\`
> **技术栈**: Python, MCP (JSON-RPC), pytest

## 组件

| 模块 | 文件 | 职责 |
|------|------|------|
| MCP 审计服务器 | `core/mcp_audit_server.py` | JSON-RPC 审计服务端点 |
| 核心审计 | `core/audit_core.py` | 审计逻辑引擎 |
| 品牌审计 | `core/brand_audit_engine.py` | 品牌合规检测 |
| AI 精修 | `content_pipeline/ai_refine_pro.py` | 内容 AI 精修 |
| 策略脚本 | `content_pipeline/2026_policy_script.py` | 2026 审计策略 |
| 平台哨兵 | `monitoring/platform_sentinel.py` | 多平台内容监控 |
| V 雷达 | `monitoring/v_radar_scanner.py` | 内容异常扫描 |
| 规则演化 | `rules_engine/rules_evolver.py` | 规则自演化 |
| Obsidian 同步 | `analysis/obsidian_sync.py` | 数据同步到 Obsidian |
