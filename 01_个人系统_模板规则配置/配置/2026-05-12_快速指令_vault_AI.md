## Obsidian AI 工具箱 (10 功能)
统一入口: `python 规则甄查系统/scripts/obsidian_ops.py <cmd> [args]`

| 指令 | 作用 |
|------|------|
| "语音笔记 {文字}" | voice — 语音/文字转笔记存收件箱 |
| "剪藏 {url}" | webclip — 网页内容剪辑入库 |
| "批量标签" | tag — 按内容语义批量加 frontmatter tags |
| "挖掘双链" | wikilink — 扫描笔记自动添加 [[内部链接]] |
| "日报" | daily — 生成今日日报模板 |
| "查知识库 {问题}" | qa — 检索 vault 内容并回答 |
| "OCR {图片路径}" | ocr — 识别图片文字存入笔记 |
| "Git 报告 [天数]" | gitviz — 分析 vault 版本变更趋势 |
| "同步 {源目录}" | sync — 外部 markdown 同步到 vault |
| "批注 {文件路径}" | annotate — 自动添加 AI 洞察批注 |
- 示例: "语音笔记 今天测试了AI集成" 或 "查知识库 伟联的服务器配置"
