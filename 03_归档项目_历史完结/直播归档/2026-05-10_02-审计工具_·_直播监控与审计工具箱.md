# 02-审计工具 · 直播监控与审计工具箱

## 自动关联数据文件
| 文件 | 用途 |
|------|------|
| `live_data*.jsonl` | 评论区 OCR 逐行数据 |
| `triage_log*.jsonl` | Triage 视觉评分记录 |
| `temp_frames/` | 全景截图存档 |
| `instructions.md` | 完整参数文档（坐标/阈值/评分公式） |

## 核心脚本
- **监控引擎**: `monitor_engine.py` / `monitor_桃.py` — 主监控
- **审计启动器**: `start_audit.py` — 依赖检查 + 交互选择 + 启动
- **报告生成**: `generate_audit_report.py` — 读取 jsonl 生成报告
- **坐标验证**: `test_coords.py` — 截图检查 CHAT_AREA 坐标
- **UI叠加**: `generate_ui_overlay.py` — 可视化标注
- **实时分析**: `realtime_analyser.py` / `analyze_stream.py`

## 快速操作
```bash
# 启动监控（交互式选目标）
python start_audit.py

# 直接启动小桃
python monitor_桃.py

# 生成审计报告
python generate_audit_report.py

# 验证坐标
python test_coords.py
```
