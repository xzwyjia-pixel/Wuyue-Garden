## 现在出现了这个问题。我无法进入你说的那个界面

看到你截图中红色的错误提示，这是因为 Firefox 的浏览器安全策略（Content Security Policy）限制了插件在当前的“扩展商店”页面运行。
关键点：Web Scraper 不能在插件安装页面（addons.mozilla.org）本身进行操作。
要进入下一步，请按照以下三个步骤操作：

第一步：切换到一个“正常”的网页
请在地址栏输入视频号的地址（或者任何一个普通网站，比如百度或搜狐），然后回车跳转：

https://channels.weixin.qq.com/platform

第二步：重新打开 Web Scraper

在视频号页面上，按下 F12（或右键点击页面选择“检查”）。
在弹出的工具栏里，再次点击最右侧的 Web Scraper 标签。

第三步：填写并创建
现在你应该能看到一个干净的创建界面，请按照下图提示填写：

Sitemap name: shipinhao_test
Start URL 1: https://channels.weixin.qq.com/platform
点击按钮: Create Sitemap


为什么之前会报错？
报错是因为你正试图在 Firefox 的官方插件商店里运行采集器。为了安全，浏览器禁止任何插件在自己的官方商店页面里执行脚本。只要换成视频号的网址，红字报错就会消失。
点击 Create Sitemap 之后：
你的界面会立即刷新，下方会出现一个蓝色的按钮：Add new selector。这就是你之前一直在找的“大门”。
按照咱们之前的计划，你要采集的是视频号评论区还是视频标题数据？成功进入下一级界面后可以告诉我，我教你如何精准“选中”那些数据。
