## 如何下载？

Tabbit 浏览器（由美团旗下的“光年之外”团队开发）目前正处于公测阶段，你可以根据需要选择国内版或国际版进行下载。
以下是具体的下载途径：
1. 官方下载地址
Tabbit 提供了适用于不同地区的官方网站，你可以直接访问并下载安装包：

国内公测版（推荐）： www.tabbit-ai.com

目前处于公测期间，免费且无需邀请码。


国际版： www.tabbitbrowser.com

国际版在底层模型的调用上与国内版有所不同，更适合海外用户或特定需求。



2. 支持的操作系统
Tabbit 基于 Chrome 内核开发，目前对桌面端支持非常完善：

Windows： 需要 Windows 10 或更高版本。
macOS： 同时支持 Apple Silicon (M1/M2/M3 芯片) 和 Intel 芯片的 Mac。

3. 安装提示

数据迁移： 由于采用 Chrome 内核，你在安装后可以实现“无痛迁移”，一键导入 Chrome 或 Edge 的书签、历史记录和保存的密码。
插件兼容： Tabbit 完美兼容所有的 Chrome 扩展插件，你可以在下载安装后直接在 Tabbit 内访问 Chrome 网上应用店安装你常用的工具。


注意： 市场上存在一些同名的 Chrome 标签页管理插件（如 Tabbit - Reddit 背景插件），如果你追求的是那款“原生 AI 浏览器”，请务必通过上述 tabbit-ai.com 官网下载独立客户端，而不是在插件商店搜索。
