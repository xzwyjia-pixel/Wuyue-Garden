## Prompted

现在的局势非常清晰了：由于 Gitee 官方源也开启了鉴权保护（Authentication failed），导致 git clone 并没有成功，所以你后面的 cd 和 pip 才会提示找不到文件。
既然网络下载这条路被各种“门禁”卡住了，我们直接换一种绝对可行的方案：手动绕过 Git。
请按照以下步骤操作，我们要用最原始但最可靠的方式把文件夹建立起来：
第一步：手动下载项目压缩包

打开浏览器，访问这个地址：[https://gitee.com/RVC-Boss/GPT-SoVITS](https://gitee.com/RVC-Boss/GPT-SoVITS)
点击页面右侧绿色的 “克隆/下载” 按钮。
选择 “下载 ZIP”。
下载完成后，将压缩包解压。
关键动作：将解压后的文件夹（名字通常是 GPT-SoVITS-master）整个移动到 E:\git_project\ 目录下，并重命名为 GPT-SoVITS。


第二步：回到终端验证路径
当你手动放置好文件夹后，回到你截图中的 PowerShell 窗口，输入：
cd E:\git_project\GPT-SoVITS
ls

如果你能看到一堆文件（包括 webui.py），说明我们终于把项目“搬”进来了！

第三步：安装依赖与下载模型
现在你已经站在正确的家门口了，接下来的命令将如履平地：
# 1. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 下载模型文件 (ModelScope 通常不需要鉴权，这次会很快)
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='GPT_SoVITS/pretrained_models')"

# 3. 启动！
python webui.py

💡 为什么之前一直失败？
从截图 image_5ca4f8.png 来看，Git 的各种下载方式都因为网络环境或权限校验（Incorrect username or password）失败了。没能下载成功，自然就没有 GPT-SoVITS 文件夹，所以你执行 cd 时系统会告诉你 it does not exist。
手动下载并解压是最后的“大招”。请完成后告诉我，如果你在 pip install 时遇到任何报错，我也在这里守着。
