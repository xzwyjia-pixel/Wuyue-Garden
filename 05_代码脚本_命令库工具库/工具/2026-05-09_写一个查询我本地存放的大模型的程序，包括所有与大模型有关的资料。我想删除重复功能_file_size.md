## 写一个查询我本地存放的大模型的程序，包括所有与大模型有关的资料。我想删除重复功能的内容

要实现查询本地大模型文件及相关资料，并识别重复内容，最高效的方法是利用 Python 编写一个脚本。考虑到大模型文件（如 .safetensors, .gguf, .bin）体积巨大，我们不能直接比较文件内容，而应采用 哈希校验（Hash） 的方式来精准锁定重复项。
以下是一个完整的工具脚本，它可以递归扫描指定目录，建立文件清单，并找出重复的资源。
Python 脚本：大模型资源清理专家
import os
import hashlib
from pathlib import Path
from collections import defaultdict

# --- 配置区 ---
# 填写你存放模型的根目录，例如 E:/Models 或 /Users/name/ai_models
SCAN_DIRECTORIES = [
    r"E:\MyCodeProjects", 
    r"D:\AI_Resources"
]

# 关注的文件后缀
MODEL_EXTENSIONS = {
    '.safetensors', '.gguf', '.bin', '.pth', '.onnx', 
    '.ckpt', '.json', '.txt', '.md', '.py'
}

def get_file_hash(file_path, chunk_size=1024*1024):
    """
    计算文件哈希值。为了兼顾大文件效率，只读取部分内容或全文。
    这里使用 MD5 算法。
    """
    hash_md5 = hashlib.md5()
    try:
        with open(file_path, "rb") as f:
            # 针对超大文件，可以只校验开头和结尾，或者全文校验以保准确
            for chunk in iter(lambda: f.read(chunk_size), b""):
                hash_md5.update(chunk)
        return hash_md5.hexdigest()
    except Exception as e:
        return f"Error: {e}"

def scan_models():
    file_map = defaultdict(list)
    total_size = 0
    
    print("🔍 正在扫描本地大模型资料...")
    
    for root_dir in SCAN_DIRECTORIES:
        for path in Path(root_dir).rglob('*'):
            if path.is_file() and path.suffix.lower() in MODEL_EXTENSIONS:
                file_size = path.stat().st_size
                # 获取唯一标识：文件名 + 大小 (初步筛选)
                file_key = (path.name, file_size)
                file_map[file_key].append(str(path))
                total_size += file_size

    print(f"✅ 扫描完成。共发现相关文件 {sum(len(v) for v in file_map.values())} 个。")
    return file_map

def find_duplicates(file_map):
    print("⚖️ 正在深度比对重复内容（计算哈希值）...")
    duplicates = []
    
    for (name, size), paths in file_map.items():
        if len(paths) > 1:
            # 只有大小和名称相同时，才触发耗时的哈希计算
            hash_registry = defaultdict(list)
            for p in paths:
                h = get_file_hash(p)
                hash_registry[h].append(p)
            
            for h, p_list in hash_registry.items():
                if len(p_list) > 1:
                    duplicates.append(p_list)
                    
    return duplicates

if __name__ == "__main__":
    results = scan_models()
    dup_list = find_duplicates(results)
    
    if not dup_list:
        print("✨ 恭喜！未发现内容重复的模型文件。")
    else:
        print(f"\n🚩 发现以下重复内容（建议删除多余副本）：")
        print("-" * 50)
        for i, group in enumerate(dup_list):
            print(f"组 {i+1}:")
            for p in group:
                size_gb = os.path.getsize(p) / (1024**3)
                print(f"  - [{size_gb:.2f} GB] {p}")
        print("-" * 50)
        print("💡 提示：请手动根据以上路径删除不需要的副本，本程序不自动执行删除操作以保安全。")


程序功能说明

多路径扫描：你可以通过修改 SCAN_DIRECTORIES 列表，同时扫描多个盘符或文件夹。
精准识别：

初步筛选：先通过“文件名+文件大小”进行快速聚类，避免对所有文件计算哈希，极大提升速度。
深度校验：对疑似重复的文件进行 MD5 哈希计算，确保内容完全一致（即使文件名被修改过，只要内容没变也能识别）。


支持多种格式：不仅包含权重文件（.gguf, .safetensors），还涵盖了配置文件（.json）和说明文档（.md）。

进阶建议

关于删除：考虑到大模型文件的珍贵性，脚本仅输出路径，不建议程序自动执行 os.remove()。建议根据输出结果手动清理，或在脚本最后添加一个交互式确认环节。
重复功能判定：如果你指的“重复功能”是指两个不同模型但效果类似（例如两个不同的 Llama-3 压缩版），这属于语义分析范畴。目前的脚本针对的是物理文件级别的完全重复。

如果你需要对特定的 MCP 配置文件或 GitHub 仓库资料进行清理，只需将相关的路径添加到 SCAN_DIRECTORIES 即可。
