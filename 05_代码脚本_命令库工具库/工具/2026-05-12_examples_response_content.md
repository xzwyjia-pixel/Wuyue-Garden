Do not use `grep`/`sed` —\nJSON strings can contain any character and regex parsing will break on quotes,\nescapes, or multi-line content.\n\n```bash\n# Capture the response, then extract -d '{\"model\":\"claude-opus-4-7\",\"max_tokens\":16000,\"messages\":[{\"role\":\"user\",\"content\":\"Hello\"}]}')\n\n# Print the first text block (-r strips the JSON quotes)\necho \"$response\" | jq -r '.content[0].text'\n\n# Read usage fields\ninput_tokens=$(echo \"$response\" | jq -r '.usage.input_tokens')\noutput_tokens=$(echo \"$response\" | jq -r '.usage.output_tokens')\n\n# Read stop reason
