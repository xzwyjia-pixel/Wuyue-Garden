## 1. 写一个程序，用于检测电脑中现在已经不用的又占用空间的安装文件。
2. 删除哪些不影响电脑使用的文件安装包

清理电脑中的安装文件（如 .exe, .msi, .dmg, .pkg 等）是释放磁盘空间的有效手段。通常，这些文件在软件安装完成后就不再需要了。
以下为您提供一个基于 Python 的自动化脚本，以及一份安全删除指南。

1. 自动化检测程序 (Python)
该程序会扫描常见的下载和缓存目录，列出占用空间的安装包文件。为了安全起见，它仅执行检测并列出清单，不会自动删除。
import os

def find_installers(search_paths):
    # 定义常见的安装包后缀
    installer_extensions = ('.exe', '.msi', '.dmg', '.pkg', '.zip')
    found_files = []

    print(f"{'文件名':<50} | {'大小 (MB)':<10}")
    print("-" * 65)

    for path in search_paths:
        if not os.path.exists(path):
            continue
            
        for root, dirs, files in os.walk(path):
            for file in files:
                if file.lower().endswith(installer_extensions):
                    file_path = os.path.join(root, file)
                    try:
                        file_size = os.path.getsize(file_path) / (1024 * 1024)
                        # 仅列出大于 50MB 的大型安装包，避免误删小工具
                        if file_size > 50:
                            found_files.append((file, round(file_size, 2), file_path))
                            print(f"{file[:48]:<50} | {round(file_size, 2):<10}")
                    except OSError:
                        continue
    
    return found_files

# 常见的安装包存放路径（Windows示例）
user_home = os.path.expanduser("~")
paths_to_scan = [
    os.path.join(user_home, "Downloads"),
    os.path.join(user_home, "Desktop"),
    "C:\\Windows\\Temp",
]

installers = find_installers(paths_to_scan)
print(f"\n共检测到 {len(installers)} 个大型安装包文件。")


2. 哪些文件可以安全删除？
在清理过程中，您可以根据以下原则判断：
✅ 可以放心删除的文件

下载文件夹中的 .exe 或 .msi：只要软件已经安装成功，这些原始安装包就可以删除。如果以后需要，可以重新从官网下载。
旧版本的更新包：例如 NVIDIA 显卡驱动的安装备份（通常位于 C:\NVIDIA）、旧版微信/QQ 的安装更新文件。
压缩包 (.zip, .7z, .rar)：解压并安装完软件后，原始压缩包通常不再需要。

⚠️ 建议保留或谨慎处理的文件

大型游戏的安装资源包：某些游戏（如原神、使命召唤）在更新时会下载数 GB 的资源包，建议通过游戏启动器自带的“清理”功能处理。
驱动程序备份：如果您经常在无网络环境下重装系统，建议将重要的主板/网卡驱动包备份到外部存储。

❌ 不要手动删除的文件

C:\Windows\Installer 文件夹：这是一个隐藏文件夹，存储了卸载或修复软件时需要的特定 MSI 文件。直接删除会导致很多软件无法卸载或更新。
正在运行的软件目录内的文件：不要直接去 Program Files 文件夹下乱删。


💡 进阶建议
如果您希望更彻底、更安全地清理，推荐结合以下工具：

系统自带工具：

Windows: 搜索“磁盘清理” (Disk Cleanup) 或“存储设置”。
macOS: 点击左上角苹果图标 > 关于本机 > 存储空间 > 管理。


专业清理工具：

WizTree / WinDirStat：可视化查看哪些文件夹最占空间。
BleachBit：开源免费的清理工具，比很多商业卫士软件更干净、无广告。



提示：在运行任何清理脚本或工具前，建议先确认电脑的重要资料已完成备份。
