## Prompted

今天这一路确实有点折腾，连 Gitee 的那个私人镜像也因为权限问题拦住了我们（Authentication failed）。
既然 GitHub 连不上，镜像站又报错，咱们直接动用 Git 的“强制重试”大法，同时换一个 Gitee 上完全公开、不需要登录的官方同步源。
请在 image_5cabbe.png 显示的 (venv) PS E:\git_project> 提示符后，只执行这一条命令：
git clone https://gitee.com/RVC-Boss/GPT-SoVITS.git


🚀 为什么这次会稳？

官方源： 这是项目作者在 Gitee 的镜像，通常是公开访问的，不会报“用户名密码错误”。
免登录： 之前那个报错是因为那个仓库是私有的或者需要 Access Token。
国内速度： Gitee 在国内环境下比 GitHub 稳定得多。

🚨 执行完后的下一步：
只要这行命令跑完，看到 done.，你就赢了一大半。请接着执行：
# 1. 钻进文件夹
cd GPT-SoVITS

# 2. 安装运行环境
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 下载模型文件
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='GPT_SoVITS/pretrained_models')"

我们离成功只剩最后两步了！请告诉我这次 git clone 是否成功跑出了进度条。
