1. 电脑环境检测程序 (Python)
您可以使用以下 Python 脚本检测当前电脑是否具备运行 scholar-skill 所需的关键工具和环境。
import subprocess
import sys
import os

def check_command(command, args=["--version"]):
    try:
        result = subprocess.run([command] + args, capture_output=True, text=True, timeout=5)
        if result.returncode == 0:
            return result.stdout.strip().split('\n')[0]
        return None
    except Exception:
        return None

def detect_environment():
    print("🔍 正在检测电脑 AI 开发环境...\n" + "-"*40)
    
    checks = {
        "Python 版本": ("python", ["--version"]),
        "Node.js 版本": ("node", ["--version"]),
        "Ollama 运行状态": ("ollama", ["list"]),
        "Git 安装状态": ("git", ["--version"]),
    }

    results = {}
    for name, (cmd, args) in checks.items():
        version = check_command(cmd, args)
        results[name] = version if version else "❌ 未找到 (Not Found)"
        print(f"{name}: {results[name]}")

    # 检测 MCP 配置文件是否存在 (默认路径)
    mcp_path = os.path.expanduser("~/.config/claude-desktop/config.json")
    if not os.path.exists(mcp_path):
        mcp_path = os.path.expanduser("~/AppData/Roaming/Claude/config.json") # Windows 路径
    
    print(f"MCP 配置文件状态: {'✅ 已找到' if os.path.exists(mcp_path) else '❓ 未找到 (通常在初次配置时创建)'}")
    print("-"*40)
    return results

if __name__ == "__main__":
    detect_environment()

2. 还需要安装的软件清单
根据 scholar-skill 的特性（高 Token 消耗、学术解构、长异步任务），您通常需要以下补充组件：

MCP Inspector：用于在集成到 VS Code 前测试技能是否正常工作的官方调试工具。

3. 第一步应该做什么？
第一步：获取并“打包”技能代码。
由于 scholar-skill 这类工具通常以“技能包”形式分发，您需要先将它下载到本地。

创建目录：在您的 AI 项目文件夹下创建一个 skills 文件夹。
获取源码：将 scholar-skill 的文件夹存放在此处。
运行 pip install：在终端进入该技能目录，执行 pip install -e . 或 pip install -r requirements.txt，确保它的“学术解构”逻辑所需的库（如 arxiv、pypdf 等）已就绪。
