## Prompted

看到报错了。这个 PermissionError: [WinError 5] 拒绝访问 是因为你当前是在 C:\Windows\System32 路径下尝试写入文件，而这个系统目录是受到保护的，且你并没有进入我们预设的 D: 盘工作目录。
另外，截图显示你直接在全局环境执行了 pip，这会污染你的全局 Python 环境，这与我们极简精密、不污染全局的初衷不符。
请按照以下步骤“纠偏”，回到正确的轨道上：
1. 切换到正确的磁盘和目录
首先，你需要离开系统盘，进入你创建好的项目文件夹。在 PowerShell 中输入：
# 切换到 D 盘
d:

# 进入项目目录
cd git_project\GPT-SoVITS

2. 激活虚拟环境 (关键)
之前我们创建了 venv，现在必须激活它，这样所有的安装和下载才会留在 D 盘的文件夹内。
# 激活虚拟环境
.\venv\Scripts\activate

激活成功后，你的命令行开头应该会出现 (venv) 字样。
3. 在虚拟环境内重新执行下载
由于你刚才在全局环境已经安装了 modelscope，现在我们需要在虚拟环境内确保它存在，然后再次运行下载命令：
# 1. 在虚拟环境内安装 modelscope
pip install modelscope -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 重新运行下载脚本（此时路径 './GPT_SoVITS/pretrained_models' 就会指向 D 盘了）
python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='./GPT_SoVITS/pretrained_models')"

为什么会报错？

权限问题： C:\Windows\System32 是 Windows 最核心的系统文件夹，普通程序（甚至是非管理员运行的 Python）不允许在这里创建新文件夹（即 ./GPT_SoVITS）。
路径误解： . 代表当前目录。你在 System32 下运行，. 就是 System32；你在 D 盘项目下运行，. 才是你的项目目录。

请先执行 d: 和 cd 命令切换路径，然后再激活环境。如果激活环境时报错（比如脚本执行策略受限），请告诉我，我给你解决权限的命令。
