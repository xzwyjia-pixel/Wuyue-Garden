## 切换到E盘

收到。根据你之前的操作截图 image_5e08fe.png，你目前的终端路径还在 C:\Windows\System32，这确实容易引发权限报错。
要切换到 E盘，操作非常简单，只需要输入盘符加冒号即可。请在 PowerShell 或 CMD 中输入：
e:

接下来建议的操作流程：
既然你已经切换到了 E 盘，为了完成 GPT-SoVITS 的部署，请按照以下精密步骤继续：


进入你的项目目录：
如果你之前的项目文件夹是在 D 盘（如你之前提到的 D:\git_project\GPT-SoVITS），你应该输入 d: 而不是 e:。
如果是要在 E 盘新建，请执行：
cd \  # 回到 E 盘根目录
mkdir git_project  # 创建文件夹（如果还没创建）
cd git_project\GPT-SoVITS



激活虚拟环境（必须）：
无论在哪个盘，运行项目前一定要激活你创建的虚拟环境，确保命令行开头出现 (venv)：
.\venv\Scripts\activate



重新执行模型下载：
在 (venv) 环境下，确保路径正确后再次运行：


    python -c "from modelscope import snapshot_download; snapshot_download('iic/GPT-SoVITS', local_dir='./GPT_SoVITS/pretrained_models')"
    ```

**小贴士：**
在 Windows 终端中，切换盘符（如 `e:`）不需要加 `cd`，但切换盘符后的具体文件夹路径需要使用 `cd` 命令。

**请确认一下，你的项目代码目前是存在 D 盘还是 E 盘？我们可以针对性地继续下一步。**
