## 🛠️ 核心引擎安装与配置手册 (2026版)

### 1. 外部 OCR 引擎下载 (必须安装)
由于 `pytesseract` 库只是一个 Python 调用接口，您必须在 Windows 系统中安装 Tesseract-OCR 本体才能识别图片文字。

*   **软件名称：** Tesseract OCR 5.x (64-bit)
*   **官方下载链接：** [tesseract-ocr-w64-setup-5.3.3.exe](https://digi.bib.uni-mannheim.de/tesseract/tesseract-ocr-w64-setup-5.3.3.20231005.exe)
*   **安装关键步骤：**
    *   在 `Choose Components` 环节，展开 **"Additional script data"** 和 **"Additional language data"**。
    *   **务必勾选：** `Chinese (Simplified)` (简体中文) 和 `English`。
