第一步：完成初始化配置
在您当前的界面中：

选择主题：直接按 Enter (回车) 选择默认的 Dark mode（或者根据喜好用方向键切换）。
确认语法高亮：界面底部显示 Monokai Extended，这非常适合代码阅读，直接保持默认即可。
进入交互界面：配置完成后，您会看到一个类似于对话框的界面，这就是您的 AI 操作台。


第二步：挂载 scholar-skill (核心环节)
现在要把 image_054a58.png 中的学术解构能力赋予这个环境。

定位配置文件：

在之前的检测中，您的配置文件路径已确认为：
...\saoudrizwan.claude-dev\settings\cline_mcp_settings.json


写入 MCP 配置：

打开该 JSON 文件，将 scholar-skill 填入 mcpServers 对象中。
关键点：确保 args 中的路径指向您存放 scholar-skill 源码的 main.py 或 index.py 文件。



{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": ["C:/你的存放路径/scholar-skill/main.py"],
      "env": {
        "PYTHONPATH": "C:/你的存放路径/scholar-skill"
      }
    }
  }
}


第三步：安装依赖并运行
该技能具备 L1-L3 分级阅读策略 和 2.5 小时长异步任务 功能，需要确保 Python 环境中有相应的库：

打开新的 PowerShell（不要关掉当前的 Claude 窗口）。
执行安装：
cd C:\你的存放路径\scholar-skill
pip install -r requirements.txt
