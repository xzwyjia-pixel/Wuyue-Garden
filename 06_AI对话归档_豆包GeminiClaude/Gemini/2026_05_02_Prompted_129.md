## Prompted

从你的终端截图来看，环境准备（第一步）已经完美通过了。你已经成功安装了 mcp 及其所有相关的 Python 依赖项。
接下来我们需要进入实操阶段，把这个技能真正运行起来。

第二步：获取 Skill 核心文件
你需要一个存放这个 tutor-skills 脚本的地方。

创建目录：
在你的 E: 盘（从截图看你的 Python 装在 E 盘）或者你习惯的地方新建一个文件夹，例如：E:\MCP-Skills\。
准备脚本：
由于 tutor-skills 通常是一个 Python 脚本（比如 tutor_server.py），你需要确保该文件已经下载并放入上述文件夹中。


第三步：配置 VS Code 挂载
这是最关键的一步，我们需要让你的 AI 助手（如 Cline 或其他支持 MCP 的插件）能够识别并调用它。


找到配置文件：
按下 Win + R，输入 %APPDATA% 并回车。
依次进入：Code -> User -> globalStorage -> saoudrizwan.claude-dev -> settings。
找到 cline_mcp_settings.json 文件并用 VS Code 打开。


写入配置信息：
在 mcpServers 大括号内添加以下内容（注意替换你的实际文件路径）：


{
  "mcpServers": {
    "tutor-skills": {
      "command": "python",
      "args": [
        "E:\\MCP-Skills\\tutor_server.py" 
      ],
      "env": {},
      "disabled": false
    }
  }
}


提示：路径中的反斜杠建议写成双反斜杠 \\ 以防报错。


第四步：激活并开始学习

重启插件：保存 JSON 文件后，在 VS Code 侧边栏重启你的 MCP 插件。
下达指令：
现在你可以直接对 AI 说：

“请使用 tutor-setup 扫描我当前的项目文件夹，帮我建立 StudyVault。”



为什么这个对你很重要？
你之前提到在进行 Python 内容审核技能 的开发，这个 tutor-skills 的“交互式测试”功能（tutor）正好可以用来检验你写的审核逻辑是否严密。它会像个导师一样，根据你写的代码反问你问题，帮你查漏补缺。
