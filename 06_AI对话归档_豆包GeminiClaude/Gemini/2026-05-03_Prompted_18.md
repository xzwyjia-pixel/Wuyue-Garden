## Prompted

你现在进入的是 Chrome 浏览器的“站点权限”设置页面，这里是管理摄像头、麦克风等底层权限的地方，并不是插件的功能配置页面。
要找到填写 API Key 的地方，请直接点击下方这个链接（你可以直接将其复制到浏览器地址栏并打开）：
chrome-extension://pklblaefkkcmofjcobdmcflmdphepcnp/options/options.html
如果手动找的话，请看这里：
1. 回到“管理扩展程序”主页
点击你截图左侧菜单栏底部的 “扩展程序” 图标（旁边带个小方框箭头的那个）。
2. 找到“扩展程序选项”
回到 MarkDownload 的主管理卡片页面后（就是你上一轮截图显示的页面）：

不要点页面中间的任何条目。
向下滚动，找到 “扩展程序选项” (Extension options) 这一行文字，点击它。

3. 配置 Obsidian
在新打开的页面中：

在左侧菜单点击 Obsidian Settings。
在 Obsidian API Key 框中粘贴你的 Key。
点击页面底部的 Save。


特别提醒：
配置完成后，如果点击“Sync to Obsidian”依然没反应，请检查你的 Obsidian 软件是否正处于打开状态，并且里面的 Local REST API 插件已启用。如果遇到“安全连接”报错，记得按照我之前说的，点击 [https://127.0.0.1:27124](https://127.0.0.1:27124) 链接并选择“继续访问”进行授权。
