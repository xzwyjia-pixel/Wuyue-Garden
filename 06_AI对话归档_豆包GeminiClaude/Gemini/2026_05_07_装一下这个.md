## 装一下这个

看来您是要把 Claude Code 的“三剑客”都凑齐。Skill-creator 是一个非常实用的工具，它能帮您把复杂的指令或工作流封装成一个简单的自定义命令（Skill）。
安装步骤非常直接，请在您的 Claude Code 终端里输入：
1. 安装命令
/install-skill skill-creator


2. 这个工具能做什么？
安装完成后，您就可以通过简单的对话让 Claude 帮您“写技能”了。例如：

封装流程： “帮我创建一个叫 audit 的 Skill，要求是读取当前目录的 Python 文件并按我的规则做风险检查。”
自动化任务： 它可以把您平时重复的操作打包，下次只需输入 /audit 就能执行一连串动作。

3. 如何查看已安装的技能？
如果您想确认是否安装成功，或者看看现在手头有哪些“武器”，可以输入：
/skills


💡 进阶小贴士
既然您已经装了 Claude-hud 和 Skill-creator：

HUD 负责在下面帮您“盯着”余额和进度；
Skill-creator 负责帮您“制造”高效工具。

这两个配合起来，您的 AI 审计和规则检查工作流就会变得非常顺手。如果在安装时提示权限问题，记得像刚才那样选 Yes (或者按键盘上的 2) 允许它读取配置文件。
安装好了吗？您可以试着让它为您创建一个专属的审计小助手。
