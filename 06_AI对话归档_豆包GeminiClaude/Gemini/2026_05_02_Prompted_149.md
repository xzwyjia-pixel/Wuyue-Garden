## Prompted

甄先生，从最新的截图来看，目前的情况非常清晰：Claude Code 并没有执行您的命令，而是把它当成了“需要联网搜索的问题”，所以它触发了 WebSearch 并在那里“空转”（Churned for 44s）。
我们需要用一个更直接、具有强制性的指令来打破这个循环。请直接在终端输入这一行：

“I need to add an MCP server. Use your 'write_to_file' tool to create or update the configuration file at '%APPDATA%/Claude/config.json' with the following content:”
{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": ["C:/AI_Skills/scholar-skill/main.py"],
      "env": {
        "PYTHONPATH": "C:/AI_Skills/scholar-skill"
      }
    }
  }
}


💡 为什么这个指令会奏效？

绕过搜索：它明确要求使用 write_to_file 工具，而不是去联网搜索。
强制路径：指定了 %APPDATA%/Claude/config.json 这个标准路径。
自动化执行：一旦它调用工具写入成功，配置就会立即生效。

输入并发送后，如果它提示“File updated”或“Done”，请再次输入 /mcp。
只要看到 scholar-skill 出现，我们就能立刻开始分析西工大航天学院的专业细节了！如果它还是去搜索，请告诉我，我带您手动去 Windows 文件夹里“强行注入”。
