## Prompted

根据您运行的检测脚本结果，您的电脑环境已经非常接近“开箱即用”的状态了。Python、Node.js 和 Git 全部就绪，且脚本成功定位到了 Cline 的 MCP 配置文件。

环境现状诊断

✅ 核心环境完美：Python 3.10.6、Node.js v20.18.0 和 Git 均已安装。
⚠️ Ollama 状态：虽然安装了 Ollama，但检测时它没有运行（Could not connect）。
📍 MCP 路径：您的配置文件位于：
...\saoudrizwan.claude-dev\settings\cline_mcp_settings.json
这确认了您正在使用 Cline (原 Claude Dev) 插件。


第一步应该做什么？
要安装 scholar-skill，您目前最紧迫的第一步是 启动 Ollama 服务并运行模型。没有模型作为“大脑”，Skill 只是死代码。
1. 唤醒“大脑” (Ollama)

在 Windows 任务栏搜索并打开 Ollama。
打开一个新的 PowerShell 窗口，输入：
ollama run qwen2.5-coder (或者您之前配置的其他模型)
确保模型能正常对话。

2. 下载 Skill 源码
既然 Git 已经装好了，请在终端执行以下操作（假设您将技能放在 C:\AI_Skills）：
mkdir C:\AI_Skills
cd C:\AI_Skills
git clone [这里填入scholar-skill的仓库地址] 
cd scholar-skill
pip install -e .

(注意：如果您没有仓库地址，可以先手动将文件解压到该目录)
3. 配置 Cline 识别该 Skill
这是最关键的“手把手”环节。请打开您的 VS Code，按照以下步骤操作：

在 Cline 面板中找到 Settings (齿轮图标)。
点击 MCP Config。
在弹出的 cline_mcp_settings.json 文件中，添加以下内容：

{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": [
        "C:/AI_Skills/scholar-skill/index.py" 
      ],
      "alwaysAllow": []
    }
  }
}

请注意：args 里的路径必须指向 scholar-skill 文件夹内真正的入口文件（通常是 index.py 或 main.py）。

接下来做什么？
完成上述配置后，保存 JSON 文件。回到 Cline 聊天界面，您应该会看到一个小积木图标或提示 scholar-skill 已连接。
您可以试着对 Cline 说：

“请使用 scholar-skill 帮我分析一下最新的 AI 智能体研究论文。”

如果执行时报错，请把报错信息发给我，我们来解决那个“人类确认防呆机制”。
