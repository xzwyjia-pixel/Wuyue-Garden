## API Provider找不到

甄先生，如果在齿轮图标的 Settings（设置）里翻找，确实很难直接看到下拉菜单，因为 VS Code 的标准设置界面通常是列表式的。
Cline 的配置其实是在它自己的对话面板里，操作非常直观。请按以下步骤操作：
1. 找到“机器人”面板
在 VS Code 最左侧的侧边栏，点击那个类似正方形机器人头的图标（也就是 Cline 的图标）。
2. 进入设置界面
点击后，你会看到 Cline 的聊天主窗口。在窗口的右上角，有一个齿轮（Settings）图标，点击它。

3. 在设置面板中配置（见下表）
进入这个特定设置页后，你就能看到 API Provider 的下拉框了。请按下表精密配置：

💡 为什么之前的设置里找不到？
VS Code 自带的“扩展设置”通常只用来调颜色、字体等基础参数；而像 Cline 这种复杂的 AI 代理，它为了交互方便，把 API 核心配置 直接做进了它自己的对话 UI 里。
一旦你配置好并点击下方的“Done”或“Save”，你应该就能看到对话框了。 此时，你就可以输入我刚才给你的那段**“超级规则”**指令，正式开启你的“规则甄查”自动化项目了。如果点击机器人图标后没反应，或者右上角找不到齿轮，发个全屏截图给我，我帮你定位！
