## Prompted

太棒了！这次的界面完全正确。你已经成功切换到了视频号的登录页面，并且打开了 Web Scraper 的创建面板。
现在的临门一脚非常简单，请跟着我做：
第一步：点击创建按钮
直接点击你截图左下方的那个蓝色按钮：Create Sitemap。
第二步：进入 Selector（选择器）界面
点击完那个蓝色按钮后，下方的面板内容会发生变化。你会看到界面变成了类似下面这样：

顶部菜单多了一个 Sitemap (Shipinhao)。
界面中心会出现一个蓝色的按钮，上面写着 Add new selector。

第三步：为什么你现在还没看到那个按钮？
因为 Web Scraper 需要你确认这个抓取任务的名称和起点（也就是你刚才填的那两行）。你点击 Create Sitemap 就相当于点下了“确定”键，之后它才会带你进入配置具体抓取规则的后台。

特别提醒（针对视频号）：
你现在的网页显示的是二维码登录界面。

先扫码登录： 建议你先在网页上扫码登录进视频号后台。
登录后再操作： 登录进去后，Web Scraper 的面板依然会在下面。这时候你再点 Add new selector 去抓取里面的数据（比如评论、播放量等）才会有效。

总结操作：

点击 Create Sitemap。
扫码登录视频号。
告诉我你进到那个有 Add new selector 的蓝色按钮界面了吗？

一旦进去了，我就能教你如何用鼠标点击网页上的内容，把它们变成 Excel 表格了！
