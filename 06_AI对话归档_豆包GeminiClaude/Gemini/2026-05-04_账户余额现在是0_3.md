## 账户余额现在是0

既然余额为 0，你的 API 调用会持续触发 insufficient_balance_error 报错。要恢复你的“规则甄查”工具测试，请参考以下操作建议：
1. 领取赠送额度

实名认证： 登录 MiniMax 开放平台，检查是否已完成实名认证。通常完成认证后系统会自动发放一定的免费测试额度。
企业认证： 考虑到你是 京源公司 (Jingyuan Company) 的法定代表人，申请企业认证通常比个人账号能获得更高额度的免费 Token。

2. 少量充值激活

如果免费额度已耗尽或过期，你可以进行小额充值（如 5-10 元）。
充值后，由于你已经正确配置了 openai 库和 base_url，代码无需修改即可直接运行。

3. 检查当前模型成本

你之前在测试中使用了 abab6.5-chat 等高性能模型，这些模型的消耗速度相对较快。
在余额有限的情况下，可以尝试调用 abab5.5-chat 等更轻量、更经济的模型进行脚本审计逻辑的调试。

4. 优化审计工具逻辑
为了节省余额，在开发你的 Python 审计工具时，可以考虑以下策略：

本地预过滤： 先通过你之前开发的 audit_tool.py 进行本地敏感词库过滤。
按需调用： 只有当本地过滤无法确定语义风险（如隐晦的违规表达）时，再调用 MiniMax API 进行深度审计。

完成充值或领取额度后，你只需要在 PowerShell 中再次运行你的脚本即可。
