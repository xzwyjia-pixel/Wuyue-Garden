## Prompted

从您的截图 image_045238.png 来看，您已经在 Claude Code 中输入了 /mcp 指令，但目前的输出显示它正在调用 WebSearch 尝试联网，并没有直接列出我们期待的 scholar-skill。
这通常意味着 Claude Code 终端还没有“看到”您在 VS Code 插件里修改的配置文件。

🛠️ 关键纠偏：同步配置文件路径
Claude Code 和 VS Code Cline 插件 有时会使用不同的配置文件路径。要让 scholar-skill 真正跑起来，请按以下步骤操作：
1. 确认 Claude Code 的配置路径
在当前的 Claude Code 终端中输入以下命令，查看它到底在读取哪个文件：
/config

请留意输出结果中提到的 config.json 路径。通常在 Windows 上，它可能位于：
%APPDATA%\Claude\config.json
2. “搬运”配置信息
如果发现路径与 Cline 插件的路径不同，您需要将之前准备好的 scholar-skill 配置复制到这个文件中：

打开该文件：您可以用 VS Code 直接打开那个路径下的 config.json。
粘贴以下内容（请根据您实际存放 skill 的位置修改 args）：

{
  "mcpServers": {
    "scholar-skill": {
      "command": "python",
      "args": ["C:/AI_Skills/scholar-skill/main.py"],
      "env": {
        "PYTHONPATH": "C:/AI_Skills/scholar-skill"
      }
    }
  }
}

3. 重启并验证
回到 Claude Code 终端，输入：
/exit

然后再次运行：
ollama launch claude --model qwen2.5-coder

再次输入 /mcp。这一次，您应该能看到 scholar-skill 作为一个可用工具出现在列表中。

🚀 开启学术解构模式
一旦列表里出现了 scholar-skill，您就可以开始发挥它在 image_054a58.png 中提到的强大功能了：

分级阅读策略：您可以指定 L1（摘要）、L2（核心论点）或 L3（深度解构）。
异步任务：如果论文非常长，您可以让它在后台处理。

甄先生，建议您现在测试这个指令：

“请调用 scholar-skill，对本地路径（或 URL）下的论文进行 L2 级解构，重点提取关于‘航天级机器人感知系统’的创新点。”

如果在 /config 中看到的路径让您感到困惑，请把路径发给我，我告诉您具体去哪里改文件。
