## superpower如何安装

如果你是指的是 Superpower ChatGPT（一个非常受欢迎的浏览器扩展程序，用于增强 ChatGPT 的功能），安装过程其实非常简单。它主要通过浏览器的扩展商店进行分发。
以下是针对不同浏览器的安装步骤：

1. 在 Google Chrome / Edge 浏览器上安装
由于 Edge 兼容 Chrome 插件，这两者的步骤基本一致：

打开 Chrome 网上应用店 (Chrome Web Store)。
在搜索栏输入 “Superpower ChatGPT”。
找到由 superpowerdaily.com 提供的对应插件。
点击 “添加至 Chrome” (Add to Chrome)。
在弹出的确认框中点击 “添加扩展程序”。
安装完成后，刷新你的 ChatGPT 页面，你会看到左侧边栏和上方出现了新的功能按钮（如文件夹、提示词库等）。

2. 在 Firefox (火狐) 浏览器上安装

打开 Firefox Browser ADD-ONS 网站。
搜索 “Superpower ChatGPT”。
点击 “添加到 Firefox”。
按照提示完成权限确认即可。


常见功能亮点
安装成功后，你可以直接在 ChatGPT 界面使用以下“超能力”：

管理文件夹： 将对话分类存放，不再乱糟糟。
提示词库 (Prompt Library)： 内置数千个现成的指令模版。
搜索与导出： 快速搜索历史对话，或将聊天记录导出为 Markdown/PDF/JSON。
自定义设置： 改变 ChatGPT 的语言模型设置、响应速度等。


💡 小提示

如果无法访问 Chrome 商店： 你可能需要通过合法的网络途径访问，或者搜索该插件的 .crx 离线安装包（但为了安全，强烈建议优先使用官方商店）。
版本兼容： 确保你的浏览器版本是最新的，否则某些高级 UI 功能可能会显示异常。
