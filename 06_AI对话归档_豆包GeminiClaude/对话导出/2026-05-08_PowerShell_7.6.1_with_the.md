cd E:\Projects\SmartIcon

如果它提示目录不存在，它会问你是否创建，输入 y。
2. 启动“全自动编程”超级指令
进入正确目录后，一次性把这个经过精密调优的 Prompt 发给它。这个指令避开了 Windows 常见的权限陷阱：
The target folder is E:\Projects\SmartIcon. Please execute these tasks:

1. Create 'engine.py':
   - MUST: Use 'ctypes.windll.shell32.IsUserAnAdmin()' to verify privileges.
   - MUST: Write 'desktop.ini' using 'utf-16' encoding with BOM.
   - MUST: Set folder attribute to READONLY (0x01) and 'desktop.ini' to HIDDEN|SYSTEM (0x06).
   - MUST: Use 'SHChangeNotify(0x08000000, 0, None, None)' for instant refresh.

2. Local Test Run:
   - Create a subfolder 'TestFolder' in the current directory.
   - Use 'C:\Windows\System32\shell32.dll,3' (the default icon) to test.
   - If success, print "SUCCESS: Icon updated!".

3. Dependency Check:
   - If 'pywin32' is needed but missing, run 'pip install pywin32' automatically.


💡 为什么这样做更稳？

编码锁定：我强调了 UTF-16 with BOM。很多 AI 默认写 UTF-8，那是 Windows 文件夹图标失效的头号原因。
属性组合：HIDDEN|SYSTEM 属性能防止用户误删 desktop.ini，保持软件稳定性。
Shell 刷新：0x08000000 (SHCNE_ASSOCCHANGED) 是最暴力的刷新方式，能确保你在资源管理器里秒看结果。
