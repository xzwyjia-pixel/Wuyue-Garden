## 我想清理一下我电脑里的所有类似cool file viewer的流氓软件，尤其是360系列的软件

针对“Cool File Viewer”和 360 系列这类具有强驻留属性、多进程守护的软件，常规的“控制面板卸载”往往无法清除干净，甚至会诱导你安装它们的全家桶。
作为一名习惯使用 Python 和脚本处理问题的专业人员，我建议你采用以下**“自动化+强力工具”**的组合拳进行清理：

🛠️ 第一阶段：使用专业卸载利器（推荐）
对于 360 系列，它们有自我保护机制，普通的卸载程序很难撼动其核心驱动。

Geek Uninstaller (免费/免安装)

优点： 卸载后会自动扫描注册表和残留文件。
操作： 选中 360 或 Cool File Viewer，点击“卸载”。如果报错，直接右键选择 “强制删除”。


HiBit Uninstaller

这是目前清理流氓软件最彻底的工具之一，自带的 “流氓软件扫描” 功能可以一次性揪出躲在系统深处的插件。




💻 第二阶段：让 Claude 为你编写“强力清除脚本”
既然你正在进行 MyCodeProjects 项目，我们可以利用代码的权限优势。请将以下指令发给你的 Claude Code：

请为我编写一个 PowerShell 强力清理脚本，执行以下逻辑：

强制杀进程： 遍历并终止所有包含 360Safe, 360sd, CoolFileViewer, Assistant 关键词的进程。
禁用服务： 将相关软件的系统服务（Service）启动类型设为 Disabled。
删除安装目录： 强制递归删除 C:\Program Files (x86)\360 和相关 AppData 路径。
清理启动项： 移除注册表中 Run 和 RunOnce 下的所有流氓软件键值。



🧹 第三阶段：手动清理“顽固残留”
流氓软件最喜欢在以下三个地方留“后手”，请手动检查：
1. 计划任务 (Task Scheduler)
很多流氓软件卸载后还会自动重装，就是靠这个。

按下 Win + R，输入 taskschd.msc。
在左侧“计划任务库”中，找有没有名称奇怪的定时任务（比如：360Update 或 FileViewerUpdate），全部右键删除。

2. 浏览器劫持
360 等软件常会锁定你的浏览器主页。

检查浏览器快捷方式：右键桌面浏览器图标 -> 属性 -> 目标。
注意： 如果 .exe 后面跟着一串网址，请把网址删掉，或者直接删除快捷方式重新创建一个。

3. 用户路径残留
按下 Win + R，分别输入以下路径，删掉对应的软件文件夹：

%AppData%
%LocalAppData%
