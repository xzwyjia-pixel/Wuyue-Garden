## Gemini Voyager如何安装

Gemini Voyager 是一款专为 Google Gemini 和 AI Studio 设计的全能增强浏览器扩展插件。它提供了文件夹管理、时间轴导航、Prompt 库、LaTeX 公式一键复制以及 Mermaid 流程图渲染等功能。
由于它是一个浏览器扩展，安装过程非常简单。根据你使用的浏览器，可以通过以下几种方式安装：
1. 通过浏览器应用商店（推荐）
这是最简单、最安全的方法，支持自动更新：

Chrome / Edge (Chromium 内核)：

访问 Chrome 网上应用店。
搜索关键词 Gemini Voyager。
点击 “添加至 Chrome”（或“获取”）。
在弹出的确认框中点击 “添加扩展程序”。


Firefox：

访问 Firefox Add-ons 站点。
搜索 Gemini Voyager。
点击 “添加到 Firefox”。




2. 通过 GitHub 手动安装（开发者或测试版）
如果你需要体验最新功能，或者由于网络原因无法访问应用店，可以从 GitHub 仓库 手动安装：

前往 GitHub 的 Releases 页面，下载最新的压缩包（通常是 .zip 文件）。
将压缩包解压到本地文件夹。
打开浏览器（如 Chrome），在地址栏输入 chrome://extensions/。
在页面右上角开启 “开发者模式” (Developer mode)。
点击左上角的 “加载解压的扩展程序” (Load unpacked)。
选择你刚才解压的文件夹即可。


3. 安装后的初步设置
安装成功后，你可以按照以下步骤开始使用：

激活插件：打开 Gemini 官网，你会发现界面左侧或右侧出现了新的功能图标（如文件夹、圆点导航栏）。
配置功能：点击浏览器右上角的扩展图标（拼图形状），找到 Gemini Voyager 并点击。
自定义界面：在弹出的设置面板中，你可以调节聊天框宽度、开启或关闭“无损去水印” (Lossless De-watermarking) 等特色功能。



[!TIP]
关于数据隐私：这款插件主打隐私安全，所有数据处理均在浏览器本地完成，不会将你的聊天记录上传到外部服务器。如果你需要在多台设备间同步文件夹或 Prompt，可以选择手动开启 Google Drive 云同步功能。
