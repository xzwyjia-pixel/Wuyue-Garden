## 选哪个？

这取决于您平时是如何支付 Claude 费用的：
建议选择：


如果您有 Claude Pro/Max 订阅（网页版会员）：
请选 1. Claude account with subscription。这最简单，直接关联您的会员账号。


如果您是开发者，通过后台充值余额（按量计费）：
请选 2. Anthropic Console account。如果您之前在 API 官网（console.anthropic.com）绑过卡或充过钱，选这个。


如果您用的是公司或云平台（AWS/Azure）提供的接口：
才选 3. 3rd-party platform。



操作提示：

直接按下键盘上的 1 或 2 即可。
选完后，终端会给出一个 网址（Link） 和一个 验证码（Code）。
点击网址，在浏览器里登录后输入那个码，点确认，这边就会显示登录成功了。

登录成功后，再执行一次 /statusline claude-hud，那个漂亮的状态栏就会出现了。
